# System settings <Label type="admin" /> {#system-settings}

<DemoLink path="/settings/general" />

The System settings screen groups the global settings into four tabs. Pick a tab to see its cards. Each tab has its own save bar, so changes on one tab never touch the others.

## Tabs {#tabs}

| Tab | What it holds |
|-----|---------------|
| General | Site identity (name and tagline), the storefront figures, hero badge and contact details, and the hosting details |
| Appearance | Portal appearance, home page sections, brand colours, typography and branding (logo and icons) |
| Integrations | Tracking and chat |
| Advanced | A table of the settings that have no card of their own |

## The save bar {#save-bar}

Edit any field and the save bar of that tab shows how many changes are waiting, for example "2 unsaved changes". With nothing edited it reads "No unsaved changes".

- **Save changes** (Save all) writes every edited field on the current tab in one go.
- **Discard changes** puts every field of the current tab back to the saved value.

Secret values show as set or not set. Use **Replace** to type a new value or **Clear** to remove it; a cleared secret is removed when you save.

## Deep links {#deep-links}

The open tab is kept in the address as `?tab=`, so a tab can be bookmarked or shared. The values are `general`, `appearance`, `integrations` and `advanced`. An address without a tab, or with an unknown one, opens General.

## Advanced {#advanced}

The Advanced tab lists the settings that have no card, as a table of key, value and description. Edit a value in place and save with the tab's save bar. Keys that already have a card on another tab are not repeated here.
