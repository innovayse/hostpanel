# API-ի ակնարկ {#api-overview}

Hostpanel REST API-ն հասանելի է `/api` հասցեով՝ տեղադրման հաճախորդի պորտալի հոսթում և ադմինի հոսթում։ Այս բաժնի յուրաքանչյուր endpoint էջ գեներացվում է հենց API-ից՝ կայքի յուրաքանչյուր կառուցման ժամանակ, ուստի այստեղ նշված ուղիները, պարամետրերը և կարգավիճակները նույնն են, ինչ հայտարարված է կոդում։

Առաջինը գալիս են այն էջերը, որոնք վերաբերում են բոլոր endpoint-ներին՝ [Նույնականացում](/hy/api-reference/authentication), [Սխալներ](/hy/api-reference/errors), [Լեզուներ](/hy/api-reference/languages), [Հարցումների սահմանափակումներ](/hy/api-reference/rate-limits) և [Էջավորում](/hy/api-reference/pagination)։ Endpoint էջերը հետևում են կողային մենյուում՝ խմբավորված ըստ լսարանի, ապա՝ ըստ ոլորտի։

<Callout type="tip">
Օրինակներում հաճախորդի պորտալի հոսթի համար օգտագործվում է <code>https://panel.example.com</code>, իսկ ադմինի հոսթի համար՝ <code>https://admin.example.com</code>։ Փոխարինեք դրանք ձեր տեղադրման հասցեներով կամ օգտագործեք տեղական միջավայրը, մինչ փորձարկում եք կանչերը։
</Callout>

## Լսարաններ {#audiences}

## Ձևաչափեր {#formats}

- **JSON։** Հարցումների և պատասխանների մարմինները `application/json` են։ Սխալները `application/problem+json` են։ Տես [Սխալներ](/hy/api-reference/errors)։
- **camelCase։** Դաշտերի անունները փոխանցվելիս գրվում են camelCase-ով, օրինակ՝ `createdAt` և `totalPages`։ Թվարկումները փոխանցվում են իրենց անուններով, օրինակ՝ `"status": "Paid"`։
- **Ամսաթվեր։** ISO 8601՝ `+00:00` շեղումով, այսինքն՝ UTC, օրինակ՝ `2026-11-04T05:12:38.265306+00:00`։
- **Գումար։** JSON թիվ այն արժույթով, որը գրառումը նշում է իր `currency` դաշտում՝ դա ISO 4217 կոդ է, օրինակ՝ `USD`, ինչպես `"total": 29.98`-ում։
- **Հարցման պարամետրեր։** Դրանց անունները համեմատվում են առանց տառաչափի հաշվառման։ Endpoint էջերը դրանք ցույց են տալիս այնպես, ինչպես հայտարարված են API-ում, օրինակ՝ `Page` և `PageSize`։

## Առողջություն {#health}

```
GET /health
```

Պատասխանում է `200 OK`, քանի դեռ API-ի գործընթացը սպասարկում է հարցումներ՝

```json
{
  "status": "Ok",
  "timestamp": "2026-11-04T12:39:25.5302532+00:00"
}
```

Այն գտնվում է հոսթի արմատում, ոչ թե `/api`-ի տակ։ Մուտք չի պահանջում և չի սահմանափակվում հարցումների սահմանաչափով։ Սա կենդանության ստուգում է, ոչ թե տվյալների բազայի ստուգում՝ `200`-ը ասում է, որ գործընթացը աշխատում է, բայց ոչինչ չի ասում նրա կախվածությունների մասին։
