# Լեզուներ {#languages}

<Callout type="tip">
Ուղարկեք <code>X-Language</code>՝ հաղորդագրություններն ստանալու համար ձեր օգտատիրոջ լեզվով։
</Callout>

## X-Language վերնագիրը {#the-x-language-header}

Ուղարկեք ցանկալի լեզուն `X-Language` վերնագրում։ API-ն պատասխանում է անգլերեն, ռուսերեն և հայերեն։

Կարդացվում է միայն `X-Language`-ը։ `Accept-Language`-ը անտեսվում է, ուստի բրաուզերի լեզվի կարգավորումը API-ի կանչի վրա ազդեցություն չունի։

## Ինչն է թարգմանվում {#what-is-translated}

- **Սխալի նախադասությունը։** Յուրաքանչյուր սխալի մարմնի `detail`-ը և `errors`-ում վավերացման սխալի նախադասությունները գալիս են ձեր խնդրած լեզվով։ `type` կոդը երբեք չի փոխվում։ Օգտատիրոջը ցույց տվեք `detail`-ը, ոչ թե `title`-ը՝ սխալների մեծ մասի վերնագիրը մնում է անգլերեն։
- **Հանրային կայքի բովանդակություն։** Գրառումները, որոնք օպերատորը մուտքագրում է մի քանի լեզվով, վերադարձվում են ձեր խնդրած լեզվով, իսկ եթե գրառումը թարգմանություն չունի՝ լռելյայն լեզվով՝ գլխավոր էջի սլայդներ, կարծիքներ, գործընկերներ, սերվերների տեղակայումներ և պորտֆոլիոյի նախագծեր։

Բովանդակությունը, որը օպերատորը գրում է միայն մեկ լեզվով, վերադարձվում է ինչպես կա։

## Օրինակ {#example}

Նույն կանչը՝ բացակայող հաշիվ-ապրանքագրի դեպքում, հայերենով՝

```bash
curl 'https://panel.example.com/api/me/invoices/99999999' \
  -H 'Authorization: Bearer <token>' \
  -H 'X-Language: hy'
```

```json
{
  "type": "INVOICE_NOT_FOUND",
  "title": "Not Found",
  "status": 404,
  "detail": "Այդպիսի հաշիվ-ապրանքագիր չի գտնվել։",
  "errors": null
}
```
