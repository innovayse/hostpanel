# Դոմեններ {#domains}

## Ձեր դոմենները {#your-domains}

<!-- See it in the demo: link goes here (#615) -->

Բացեք **My Domains** բաժինը։ Էջն ունի երեք ներդիր՝ **All**, **Active** և **Expired**։

Դոմենների կարգավիճակները.

| Կարգավիճակ | Ինչ է նշանակում |
|--------|--------------|
| Active | Գրանցված է և աշխատում է |
| Pending | Գրանցումը մշակվում է |
| Pending Transfer | Ընթացքի մեջ է փոխանցումը մեկ այլ գրանցողից |
| Pending DNS | DNS-ը կարգավորվում է |
| Expired | Դոմենի ժամկետը լրացել է, և այն ակտիվ չէ |
| Grace Period | Ժամկետը վերջերս է լրացել։ Դեռ կարելի է երկարացնել սովորական գնով։ |
| Redemption | Վերականգնման փուլում է։ Կարելի է վերականգնել ավելի բարձր գնով։ |
| Transferred Out | Դոմենը փոխանցվել է մեկ այլ մատակարարի |
| Cancelled | Դոմենի գրանցումը չեղարկվել է |

Երբ դոմենը գրանցվում է, էջում երևում է **Domain Registration in Progress** գրությունը։ Երբ ընթացքի մեջ է փոխանցումը մեկ այլ գրանցողից, երևում է **Domain Transfer in Progress** գրությունը։

## Անունների սերվերներ {#nameservers}

Բացեք դոմենը և անցեք նրա անունների սերվերների կարգավորումներին։ Ընտրեք՝

- **Use default nameservers**․ օգտագործվում են ձեր հոսթինգ մատակարարի անունների սերվերները։
- **Use custom nameservers**․ մուտքագրեք ձեր սեփական անունների սերվերների հասցեները։

Պահպանեք փոփոխությունը։ DNS փոփոխությունները ամբողջ աշխարհում ուժի մեջ մտնելու համար կարող են տևել մինչև 24 ժամ։

## Արգելափակում, փոխանցման կոդ և գաղտնիություն {#lock-transfer-code-and-privacy}

| Կարգավորում | Ինչ է անում |
|---------|-------------|
| Registrar lock | Կանխում է պատահական կամ չարտոնված փոխանցումները․ անջատեք այն, նախքան դոմենը փոխանցելը մեկ այլ գրանցողի |
| Email EPP Code | Ուղարկում է թույլտվության կոդը, որն անհրաժեշտ է դոմենը մեկ այլ գրանցողի փոխանցելու համար |
| ID protection | Թաքցնում է ձեր անձնական կոնտակտային տվյալները WHOIS-ի հանրային հարցումներից |

## Դոմենի երկարացում {#renew-a-domain}

Սեղմեք **Renew Now**՝ դոմենը ժամկետը լրանալուց առաջ երկարացնելու համար։ Կարող եք նաև միացնել **auto renew**։ Երբ այն միացված է, դոմենի ժամկետը լրանալուց առաջ ավտոմատ կերպով ստեղծվում է երկարացման հաշիվ-ապրանքագիր, և դոմենը երկարացվում է այն վճարելուց հետո։

## Կոնտակտային տվյալներ {#contact-details}

Բացեք դոմենը՝ գրանցատիրոջ կոնտակտային տվյալները թարմացնելու համար։ Փոփոխությունների համար ռեեստրը կարող է հաստատման նամակ ուղարկել։

## Դոմենի փոխանցում ձեզ {#transfer-a-domain-in}

Դոմենը մեկ այլ գրանցողից այս մատակարարին փոխանցելու համար օգտվեք դոմենի որոնումից [պատվիրման](/hy/customers/ordering) ընթացքում, սեղմեք **Transfer this domain instead** և մուտքագրեք **Authorization Code**-ը ձեր ընթացիկ գրանցողից։
