# Ծառայություններ և SSH բանալիներ {#services-and-ssh-keys}

## Ձեր ծառայությունները {#your-services}

<!-- See it in the demo: link goes here (#615) -->

Բացեք **My Services** բաժինը։ Յուրաքանչյուր ծառայություն ցուցադրում է իր կարգավիճակը՝

| Կարգավիճակ | Ինչ է նշանակում |
|--------|--------------|
| Pending | Պատվերը տրված է, բայց ծառայությունը դեռ կարգավորված չէ |
| Active | Ծառայությունը աշխատում է |
| Suspended | Ծառայությունը դադարեցված է։ Մինչև վերաակտիվացումը դուք չեք կարող այն օգտագործել։ |
| Ended | Ծառայության ժամկետն ավարտվել է (ցուցադրվում է նաև որպես Terminated) |

## Կարգավորեք նոր ծառայություն {#set-up-a-new-service}

Երբ ծառայությունը կարգավորման կարիք ունի, այն ցուցադրում է **Setup Required**։

<Steps>
<li>

Սեղմեք ծառայության վրա գտնվող **Complete Setup** կոճակը։

</li>
<li>

Հետևեք կարգավորման քայլերին՝ ընտրեք դոմեն, սահմանեք մուտքի տվյալներ և ստուգեք ամեն ինչ։

</li>
<li>

Կարգավորումն ավարտվելուց հետո ծառայությունը դառնում է ակտիվ։

</li>
</Steps>

Կարգավորումը հասանելի է դառնում առաջին հաշիվ-ապրանքագիրն ամբողջությամբ վճարելուց հետո։

## Կառավարեք ծառայությունը {#manage-a-service}

Ծառայությունը բացելու համար սեղմեք դրա վրա։ **Overview** ներդիրում երևում են ձեր պլանը, վճարման տվյալները և արագ հղումները։

- **Change Password**․ մուտքագրեք նոր գաղտնաբառ և սեղմեք **Change Password**։ Պահանջում է **View & Modify Product Passwords** թույլտվությունը։
- **Login to Control Panel**․ անմիջապես բացում է ձեր հոսթինգի կառավարման վահանակը։
- **Request Cancellation**․ ընտրեք **Immediate** (չեղարկվում է անմիջապես) կամ **End of Billing Period** (գործում է մինչև ընթացիկ ժամանակաշրջանի ավարտը), մուտքագրեք պատճառը և սեղմեք **Submit Cancellation Request**։ Պահանջում է **Place New Orders/Upgrades/Cancellations** թույլտվությունը։

## SSH բանալիներ {#ssh-keys}

SSH բանալին ֆայլերի զույգ է՝ փակ բանալի, որը մնում է ձեր համակարգչում, և բաց բանալի, որը դուք ավելացնում եք սերվերում։ Միանալիս սերվերը ստուգում է, որ ձեր փակ բանալին համապատասխանում է իր մոտ պահպանված բաց բանալուն։ Ձեզ գաղտնաբառ երբեք պետք չէ, իսկ ձեր փակ բանալին երբեք չի լքում ձեր համակարգիչը։

**SSH Keys** ներդիրը թույլ է տալիս կառավարել ձեր հոսթինգ հաշվի բաց բանալիները։

Այս ներդիրը տեսնելու համար ձեր հաշվին անհրաժեշտ է **View & Modify Product Passwords** թույլտվությունը։

<!-- See it in the demo: link goes here (#615) -->

### Միացեք ձեր սերվերին {#connect-to-your-server}

Ներդիրում երևում են ձեր հաշվի **Hostname**, **Port** և **Username** արժեքները։ Պատրաստի SSH հրամանը պատճենելու համար սեղմեք **Connect with**։

### Ավելացրեք բանալի {#add-a-key}

<Steps>
<li>

Բացեք **SSH Keys** ներդիրը։ Ներդիրում երևում է **Your keys (count/max)**։

</li>
<li>

Ոլորեք մինչև **Add a key**։ Տեղադրեք ձեր բաց բանալին **Public key (ED25519)** դաշտում և մուտքագրեք **Label** (օրինակ՝ "Work laptop")։

</li>
<li>

Սեղմեք **Add key**։

</li>
</Steps>

<Callout type="danger">
Երբեք մի տեղադրեք ձեր փակ բանալին (ֆայլը, որը <em>չունի</em> .pub վերջավորություն)։ Էջը դա մերժում է, սակայն այդ սովորույթը պահեք ցանկացած կայքում։
</Callout>

Ընդունվում են միայն ED25519 բաց բանալիներ։ Եթե դեռ չունեք, նույն ներդիրում գտնվող **How do I create an SSH key?** ուղեցույցը քայլ առ քայլ կցուցադրի, թե ինչպես ստեղծել այն։

### Ավտոմատ տեղակայում GitHub-ից կամ GitLab-ից {#deploy-automatically-from-github-or-gitlab}

SSH Keys ներդիրի **Deploy automatically from GitHub or GitLab** ուղեցույցը ցույց է տալիս, թե ինչպես կարգավորել ավտոմատ տեղակայում՝ ձեր հիմնական ճյուղ յուրաքանչյուր push-ից հետո։

### Չեղարկեք բանալի {#revoke-a-key}

Սեղմեք բանալու կողքի **Revoke** կոճակը, ապա հաստատեք **Revoke this key?** հարցումը։ Բանալին հեռացվում է սերվերից։

### Բանալու կարգավիճակի նշաններ {#key-status-badges}

| Նշան | Ինչ է նշանակում |
|-------|--------------|
| Pending | Բանալին ավելացվում է սերվերում |
| Install not confirmed | Բանալին ուղարկվել է, բայց սերվերը չի հաստատել դրա ավելացումը |
| Revoke not confirmed | Չեղարկման հրահանգն ուղարկվել է, բայց չի հաստատվել |
| Off the server while the service is suspended | Բանալին պահպանված է, բայց ոչ ակտիվ՝ մինչև ծառայության վերաակտիվացումը |
| Revoked | Բանալին հեռացվել է |
| Previous server | Բանալին ավելացվել է նախորդ սերվերում և այլևս ակտիվ չէ |
| Not found on server | Բանալին սերվերում չկա։ Նորից փորձելու համար սեղմեք Retry։ |

### Երբ SSH բանալիները հասանելի չեն {#when-ssh-keys-are-not-available}

| Հաղորդագրություն | Ինչ անել |
|---------|-----------|
| "SSH access is disabled for this hosting account. Contact support to enable it." | Խնդրեք ձեր հոսթինգի մատակարարին միացնել SSH-ը ձեր հաշվի համար |
| "SSH key management is not available for this type of hosting." | Այս տիպի հոսթինգը չի աջակցում SSH բանալիների կառավարումը |
| "SSH key management is not enabled on this service's server yet." | Սերվերը դեռ կարգավորված չէ SSH բանալիների կառավարման համար։ Վերադարձեք ավելի ուշ կամ դիմեք աջակցությանը։ |
| "SSH keys can only be managed while the service is active." | Նախ վերաակտիվացրեք ծառայությունը |
| "The hosting server could not be reached. Please try again later." | Ժամանակավոր ցանցային խնդիր է։ Փորձեք մի փոքր ուշ։ |
