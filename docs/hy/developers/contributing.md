# Մասնակցություն նախագծին {#contributing}

::: warning Աշխատանքը ընթացքի մեջ է
Այս էջը դեռ գրվում է։ Վերադարձեք որոշ ժամանակ անց։
:::

## Փաստաթղթերի կայքի կարգավորումներ {#documentation-site-settings}

Փաստաթղթերի կայքը (VitePress, `docs/` թղթապանակում) բիլդի ժամանակ կարդում է երկու ըստ ցանկության միջավայրի փոփոխական։ Երկուսն էլ ունեն լռելյայն արժեքներ հանրային փաստաթղթերի կայքի համար, ուստի մասնակիցների մեծ մասը ոչինչ չի սահմանում։

| Փոփոխական | Լռելյայն | Նշանակություն |
|---|---|---|
| `DOCS_BASE` | `/docs/` | URL ուղին, որի տակ սպասարկվում է կայքը, սկզբի և վերջի շեղ գծով։ Օգտագործվում է նաև favicon հղման համար։ Սեփական դոմենի դեպքում օգտագործեք `/`։ |
| `DOCS_SITE_URL` | `https://hostpanel.innovayse.com/docs` | Հանրային origin-ը՝ base ուղով, առանց վերջի շեղ գծի։ Օգտագործվում է canonical հղումների, սոցիալական նախադիտման պատկերների URL-ների և կայքի քարտեզի համար (`sitemap.xml` base ուղու տակ)։ Պահեք այն `DOCS_BASE`-ի հետ համաձայնեցված։ |

Օրինակ, սեփական դոմենի արմատից սպասարկվող օրինակ հավաքելու համար.

```bash
DOCS_BASE=/ DOCS_SITE_URL=https://docs.example.org npm run build
```
