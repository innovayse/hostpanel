# Ֆրոնտենդներ {#frontends}

## Ադմինի վահանակի տվյալների հոսքը {#admin-panel-data-flow}

`admin/src/`-ը հետևում է խիստ քառաշերտ ուղուն։ Ոչ մի կանչ շերտ չի բաց թողնում։

```
View
  └─ store           src/stores/<area>.ts
       └─ API composable   src/composables/apis/use<Area>Api.ts
            └─ useApi
```

- **View-ները** նկարագրում են, թե ինչ ցույց տալ, և կանչում են store-ի action-ները։ Դրանք երբեք չեն կանչում `useApi`-ն անմիջապես և երբեք `catch` բլոկ չեն պարունակում։
- **Store-ները** յուրաքանչյուր API կանչ անցկացնում են `runAction`-ով և բացահայտում են `error` և `fieldErrors`՝ view-ի համար։
- **API կոմպոզաբլները** յուրաքանչյուր endpoint փաթաթում են մեկ տիպավորված ֆունկցիայի մեջ և կանչում են `useApi`։
- **`useApi`**-ն յուրաքանչյուր հարցում ուղարկում է CSRF վերնագրով և `X-Language`-ով։

## Հաճախորդի պորտալի տվյալների հոսքը {#client-portal-data-flow}

`client/`-ը ավելացնում է մեկ շերտ․ պորտալի սեփական սերվերային երթուղիները գտնվում են API կոմպոզաբլի և բեքենդ API-ի միջև։

```
Page
  └─ store
       └─ API composable
            └─ useApi
                 └─ server route   server/api/portal/**
                      └─ API
```

Շերտերի հերթականությունը պարտադրվում է lint կանոններով և `client/scripts/check-layers.mjs`-ով։ Սերվերային ռենդերով էջերի ձևանմուշները գտնվում են `client/templates/<template>/` թղթապանակում։

## Կոմպոնենտների հավաքածուն {#the-component-kit}

Երկու հավելվածներն էլ օգտագործում են նույն կոմպոնենտային կանոնները.

- View-ներում չմշակված HTML կառավարման տարրեր չկան։ Միշտ օգտագործեք հավաքածուի կոմպոնենտ։
- Յուրաքանչյուր մուտքագրման դաշտ ունի placeholder։
- Յուրաքանչյուր ինտերակտիվ տարր ունի `data-testid` ատրիբուտ `<area>-<element>` ձևաչափով։
- JSDoc յուրաքանչյուր արտահանվող ֆունկցիայի և կոմպոնենտի վրա։

## Թարգմանություններ {#translations}

Յուրաքանչյուր ոլորտ ունի լոկալի իր ֆայլերը։ Թարգմանության ցանկացած փոփոխություն push անելուց առաջ գործարկեք `lint:i18n`։

<Callout type="tip">
Թարգմանությունները push անելուց առաջ գործարկեք <code>lint:i18n</code>։ Այն բացակայող բանալիները գտնում է CI-ից շուտ։
</Callout>

Թարգմանության ամբողջական ընթացքի համար տե՛ս [Hostpanel-ի թարգմանությունը](./translating)։
