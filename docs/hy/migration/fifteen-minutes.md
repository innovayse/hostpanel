# Միգրացիայի ստուգացանկ {#migration-checklist}

<Label type="admin" />

Սա WHMCS-ից տեղափոխման կարճ ճանապարհն է։ Ձեռքով արվող քայլերը տևում են մոտ տասնհինգ րոպե։ Այնուհետև ներմուծումն աշխատում է ֆոնային ռեժիմով, ուստի տևողությունը կախված է տեղափոխվող գրառումների քանակից։ Յուրաքանչյուր կետ հղվում է [Տեղափոխում WHMCS-ից](/hy/migration/from-another-system) էջի այն բաժնին, որտեղ այն բացատրված է։

- [ ] Կարդացեք [Ինչ է պետք](/hy/migration/from-another-system#what-you-need) և [Ինչ չի ներմուծվում](/hy/migration/from-another-system#what-is-not-imported) բաժինները։
- [ ] Պահուստավորեք տվյալների բազան և `.env` ֆայլը, կարգավորեք արժույթները, սերվերները և բաժինները, տես [Նախքան սկսելը](/hy/migration/from-another-system#before-you-start)։
- [ ] Ստեղծեք առաջադրանքը, տեղադրեք հավելումը և ստուգեք միացումը, տես [Միգրացիայի ստեղծում](/hy/migration/from-another-system#create-a-migration)։
- [ ] Սկսեք ներմուծումը և հետևեք հաշվիչներին, տես [Առաջադրանքի կարգավիճակներ](/hy/migration/from-another-system#job-statuses)։
- [ ] Շտկեք բաց թողնված և ձախողված գրառումները և կրկնեք ներմուծումը, տես [Ներմուծման հաշվետվություն և բաց թողնելու պատճառներ](/hy/migration/import-report) և [Կրկնեք անվտանգ](/hy/migration/from-another-system#run-it-again-safely)։
- [ ] Ստուգեք տվյալները, տես [Ստուգեք արդյունքը](/hy/migration/from-another-system#check-the-result)։
- [ ] Հեռացրեք բանալին, հավելումը և ավարտված առաջադրանքը, տես [Տեղափոխումից հետո](/hy/migration/from-another-system#after-the-move)։
