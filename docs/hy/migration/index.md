# Միգրացիա {#migration}

Այս բաժինը նվիրված է հաճախորդների, հաշիվ-ապրանքագրերի, ծառայությունների և այլ տվյալների տեղափոխմանը WHMCS-ից Hostpanel։

- [Տեղափոխում WHMCS-ից](/hy/migration/from-another-system)՝ ինչպես է աշխատում միգրացիան, ինչ է ներմուծվում և ինչպես այն գործարկել։
- [Ներմուծման հաշվետվություն և բաց թողնելու պատճառներ](/hy/migration/import-report)՝ ինչ է նշանակում յուրաքանչյուր կարգավիճակ և ինչպես շտկել բաց թողնված գրառումները։
