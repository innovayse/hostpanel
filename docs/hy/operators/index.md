# Օպերատորի ուղեցույց {#operators-guide}

Այս էջը դեռ գրվում է։ Վերադարձեք մի փոքր ուշ։
:::

## Պլագիններ {#plugins}

- [Պլագինների ռեեստր](/hy/operators/plugin-registry)՝ դիտեք և տեղադրեք պլագիններ ռեեստրից, ընտրեք, թե ում եք վստահում, և տեսեք սահմանափակումներն ու սխալները։
