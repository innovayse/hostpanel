# Վճարումներ {#payments}

Այս բաժինը բացատրում է, թե ինչպես ընդունել վճարումներ Hostpanel-ում՝ բանկային փոխանցման և տեղադրված վճարային համակարգերի կարգավորումը, առցանց վճարումների հաստատման եղանակը և Hostpanel-ի ընդլայնումը վճարային պլագիններով։

- [Վճարային համակարգեր](/hy/payments/gateways)՝ բանկային փոխանցում, վճարային համակարգերի պլագինների տեղադրում և համակարգի մատյան
- [Ինչպես են հաստատվում առցանց վճարումները](/hy/payments/confirming)՝ համաձայնեցման աշխատանքը, գումարի ստուգումը և խնդիրների լուծումը
- [Պլագինների կառավարիչ](/hy/payments/plugins)՝ վճարային և պրովիժնինգի պլագինների տեղադրում, թարմացում և հեռացում
