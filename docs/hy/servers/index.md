# Սերվերներ և SSH {#servers-ssh}

Այս բաժինը նվիրված է սերվերների կառավարմանը, ավտոմատ պրովիժնինգին և SSH բանալիների agent-ին։

- [Սերվերներ և սերվերների խմբեր](/hy/servers/servers)՝ սերվերների ավելացում, խմբերի և լրացման կանոնի կարգավորում
- [cPanel սերվերներ](/hy/servers/cpanel)՝ WHM սերվերի միացում API թոքենով
- [Պրովիժնինգ](/hy/servers/provisioning)՝ ինչպես են պատվերները ստեղծում հոսթինգի հաշիվներ և ինչպես են աշխատում կասեցումն ու դադարեցումը
- [SSH բանալիների agent](/hy/servers/ssh-key-agent)՝ յուրաքանչյուր սերվերի բանալիների agent-ի տեղակայում և կառավարում
