# Հայտարարություններ, գիտելիքների բազա և ներբեռնումներ <Label type="admin" /> {#announcements-knowledge-base-and-downloads}

## Հայտարարություններ {#announcements}

Անցեք **Աջակցություն → Հայտարարություններ**։ Ենթավերնագիր՝ «Manage client-facing announcements.»

**Սյունակներ՝** ամսաթիվ, վերնագիր, հրապարակված։

Սեղմեք **Ավելացնել նոր հայտարարություն** և լրացրեք ձևը՝

| Դաշտ | Նշումներ |
|-------|-------|
| Վերնագիր | Հայտարարության վերնագիրը |
| Հայտարարություն | Հայտարարության տեքստը |
| Հրապարակված | Նշեք՝ հայտարարությունը հաճախորդի պորտալում ցուցադրելու համար |

**Ամսաթիվը** սահմանվում է ավտոմատ և խմբագրելիս ցուցադրվում է միայն կարդալու համար։

Հաճախորդի պորտալում երևում են միայն հրապարակված հայտարարությունները։ Գոյություն չունեցող հայտարարության դեպքում վերադարձվում է `ANNOUNCEMENT_NOT_FOUND`։

Հաճախորդները հայտարարությունները կարող են կարդալ հաճախորդի պորտալի **Հայտարարություններ** բաժնում։

## Գիտելիքների բազա {#knowledge-base}

Անցեք **Աջակցություն → Գիտելիքների բազա**։ Ենթավերնագիր՝ «Manage knowledgebase articles and categories.»

### Կատեգորիաներ {#categories}

Սեղմեք **Ավելացնել կատեգորիա** և մուտքագրեք՝
- **Կատեգորիայի անվանումը**
- **Նշեք՝ թաքցնելու համար** — թաքցնում է կատեգորիան հաճախորդի պորտալից
- **Նկարագրություն** — ցուցադրվում է կատեգորիայի էջում

Ենթակատեգորիաներ ունեցող կատեգորիան հնարավոր չէ ջնջել (`KBCATEGORY_IN_USE`)։ Գոյություն չունեցող կատեգորիայի դեպքում վերադարձվում է `KBCATEGORY_NOT_FOUND`։

### Հոդվածներ {#articles}

Սեղմեք **Ավելացնել հոդված** և լրացրեք՝
- **Վերնագիր**
- **Կատեգորիա**
- **Բովանդակություն**
- **Հրապարակված** — նշեք՝ հոդվածը հաճախորդներին տեսանելի դարձնելու համար

Գոյություն չունեցող հոդվածի դեպքում վերադարձվում է `KBARTICLE_NOT_FOUND`։

### Դիտում {#browse}

Գիտելիքների բազայի գլխավոր էջում ցուցադրվում են **Դիտել ըստ կատեգորիայի** և **Դիտել ըստ պիտակի** բաժինները։ Պիտակները վերցվում են հոդվածներից և անմիջապես կառավարվել չեն կարող։

Հաճախորդները գիտելիքների բազան կարող են կարդալ հաճախորդի պորտալի **Գիտելիքների բազա** բաժնում։

## Ներբեռնումներ {#downloads}

Անցեք **Աջակցություն → Ներբեռնումներ**։ Ենթավերնագիր՝ «Manage downloadable files and categories.»

### Կատեգորիաներ {#categories-1}

Սեղմեք **Ավելացնել կատեգորիա** և մուտքագրեք կատեգորիայի անվանումը։ Ֆայլեր կամ ենթակատեգորիաներ ունեցող կատեգորիան հնարավոր չէ ջնջել (`DOWNLOAD_CATEGORY_IN_USE`)։ Գոյություն չունեցող կատեգորիայի դեպքում վերադարձվում է `DOWNLOAD_CATEGORY_NOT_FOUND`։

### Ֆայլեր {#files}

Սեղմեք **Ավելացնել ներբեռնում** և լրացրեք ձևը՝

| Դաշտ | Նշումներ |
|-------|-------|
| Տեսակ | ZIP ֆայլ, գործարկվող ֆայլ, PDF կամ այլ |
| Վերնագիր | Հաճախորդներին ցուցադրվող անվանումը |
| Նկարագրություն | Կարճ նկարագրություն |
| Ֆայլի անունը | Տրամադրվող ֆայլի անունը |
| Կատեգորիա | Կատեգորիան, որին պատկանում է այս ներբեռնումը |
| Միայն հաճախորդների համար | Սահմանափակում է ներբեռնումը միայն մուտք գործած հաճախորդների համար |
| Ապրանքի ներբեռնում | Հասանելիության համար պահանջում է ապրանքի կամ հավելման ձեռքբերում |
| Թաքցված | Հեռացնում է ներբեռնումը հաճախորդի բաժնից |

Գոյություն չունեցող ներբեռնման դեպքում վերադարձվում է `DOWNLOAD_NOT_FOUND`։

<Callout type="note">
Ներբեռնումները կառավարվում են այստեղ, սակայն հաճախորդի պորտալում դեռ չեն ցուցադրվում։
</Callout>
