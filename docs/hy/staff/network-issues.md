# Ցանցային խնդիրներ <Label type="admin" /> {#network-issues}

Ցանցային խնդիրների միջոցով կարող եք հաճախորդներին տեղեկացնել խափանումների և պլանային աշխատանքների մասին։

## Ցանկը {#the-list}

Անցեք **Աջակցություն → Ցանցային խնդիրներ**։ Ենթավերնագիր՝ «Ցանցի կարգավիճակի և միջադեպերի հաշվետվությունների կառավարում»։

Երեք ներդիր.

| Ներդիր | Ինչ է ցույց տալիս |
|--------|-------------------|
| Բաց | Խնդիրներ «Հայտնված» կամ «Ուսումնասիրվում է» կարգավիճակով |
| Պլանավորված | Խնդիրներ «Պլանավորված» կարգավիճակով |
| Լուծված | Խնդիրներ «Լուծված» կարգավիճակով |

Գոյություն չունեցող խնդրի դեպքում վերադարձվում է `NETWORKISSUE_NOT_FOUND`։

## Խնդրի մասին հայտնել {#report-an-issue}

Սեղմեք **(+) Ստեղծել** և լրացրեք ձևը.

| Դաշտ | Տարբերակներ |
|------|-------------|
| Վերնագիր | Խնդրի վերնագիրը |
| Տեսակ | Սերվեր, Այլ |
| Սերվեր | Սերվերի անվանումը (ոչ պարտադիր) |
| Առաջնահերթություն | Ցածր, Միջին, Բարձր, Կրիտիկական |
| Սկզբի ամսաթիվ | Երբ է խնդիրը սկսվել |
| Նկարագրություն | Խնդրի մանրամասները |

Նոր խնդիրները միշտ սկսվում են **Հայտնված** կարգավիճակով։ Պահելու համար սեղմեք **Ստեղծել խնդիր**։

## Խնդրի թարմացում {#update-an-issue}

Խմբագրելու համար սեղմեք խնդրի վրա։ Խմբագրման ձևում ավելանում են երկու դաշտ.

| Դաշտ | Նշումներ |
|------|----------|
| Կարգավիճակ | Հայտնված, Ուսումնասիրվում է, Պլանավորված, Լուծված |
| Ավարտի ամսաթիվ | Երբ է ավարտվել կամ երբ է ակնկալվում ավարտվել |

## Պլանային աշխատանքներ {#planned-maintenance}

<Steps>
<li>

Սեղմեք **(+) Ստեղծել** և լրացրեք վերնագիրը, տեսակը, առաջնահերթությունը, սկզբի ամսաթիվը և նկարագրությունը։ Պահեք **Հայտնված** կարգավիճակով։

</li>
<li>

Բացեք խնդիրը, **Կարգավիճակ** դաշտում ընտրեք **Պլանավորված** և նշեք **Ավարտի ամսաթիվը**։

</li>
<li>

Աշխատանքն ավարտվելուց հետո կրկին խմբագրեք խնդիրը և **Կարգավիճակ** դաշտում ընտրեք **Լուծված**։

</li>
</Steps>

## Ինչ են տեսնում հաճախորդները {#what-customers-see}

Ցանցային խնդիրները դեռ չեն ցուցադրվում հաճախորդի պորտալում։
