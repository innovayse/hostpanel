# Աջակցության հայտեր <Label type="admin" /> {#support-tickets}

## Բաժիններ {#departments}

Նոր տեղադրման ժամանակ ստեղծվում է չորս բաժին։ Դրանց կոնտակտային հասցեները առաջին գործարկման ժամանակ կարդացվում են հետևյալ կարգավորումներից.

<SettingTable :settings="[

  { name: 'DEPARTMENT_BILLING_EMAIL', type: 'string', default: 'billing@example.com', description: 'Վճարումների բաժնի էլ. փոստի հասցեն' },

  { name: 'DEPARTMENT_GENERAL_EMAIL', type: 'string', default: 'hello@example.com', description: 'Ընդհանուր բաժնի էլ. փոստի հասցեն' },
]" />

Այս կարգավորումները կարդացվում են միայն մեկ անգամ՝ երբ բաժինների աղյուսակը դատարկ է։

<Callout type="note">
Բաժիններ ստեղծելու կամ խմբագրելու համար ադմինի վահանակում դեռ էկրան չկա։ API-ում դրա համար endpoint-ներ կան։ Արդեն գոյություն չունեցող բաժնին հղվող հայտը վերադարձնում է <code>DEPARTMENT_NOT_FOUND</code>։
</Callout>

## Հայտերի կարգավիճակները և առաջնահերթությունները {#ticket-statuses-and-priorities}

| Կարգավիճակ | Ինչ է նշանակում |
|--------|---------------|
| Բաց | Հայտը բաց է և սպասում է աշխատակցի պատասխանի |
| Սպասում է պատասխանի | Աշխատակիցը պատասխանել է, սպասվում է հաճախորդի պատասխանը |
| Փակ | Հայտը փակված է |

**Առաջնահերթություններ՝** Ցածր, Միջին, Բարձր։

## Հայտերի ցանկը {#the-ticket-list}

Բացեք **Աջակցություն → Աջակցության հայտեր**։ Ենթավերնագիր՝ «Հաճախորդների բոլոր աջակցության հայտերի կառավարում»։

**Զտիչներ՝** Բոլոր ակտիվ տոմսերը, Դրոշակավորված, Բաց, Սպասում է պատասխանի, Փակ։

**Որոնում՝** ըստ հայտի թեմայի։

**Սյունակներ՝** Թեմա, Բաժին, Հայտատու, Կարգավիճակ, Վերջին պատասխան։

**Զանգվածային գործողություններ** («Ընտրվածների հետ՝» բաժնում)՝ Փակել, Ջնջել, Նշել դրոշակով, Հանել դրոշակը։

<Callout type="warning">
Հայտի ջնջումը հնարավոր չէ չեղարկել։
</Callout>

Գոյություն չունեցող հայտը վերադարձնում է `TICKET_NOT_FOUND`։

## Պատասխանեք հայտին {#answer-a-ticket}

Սեղմեք հայտի վրա՝ դրա էջը բացելու համար։

**Տոմսի կարգավորումներ վահանակ** (աջ կողմում)՝ Բաժին, Առաջնահերթություն, Կարգավիճակ, Պահպանել փոփոխությունները։

**Նամակագրություն** — հաճախորդի և աշխատակիցների միջև հաղորդագրությունների շղթան։

<Steps>
<li>

Մուտքագրեք պատասխանը **Ավելացնել պատասխան** դաշտում։

</li>
<li>

Սեղմեք **Պատասխանել**՝ այն ուղարկելու համար։

</li>
</Steps>

**Ով է ստանում էլ. փոստի ծանուցումներ**

| Իրադարձություն | Ստացող |
|-------|-----------|
| Հայտը ստեղծվել է | Բաժնի էլ. փոստի հասցեն (`ticket-created`) |
| Աշխատակիցը պատասխանել է | Հաճախորդը (`ticket-replied`) |
| Հաճախորդը պատասխանել է | Բաժնի էլ. փոստի հասցեն (`ticket-replied`) |
| Հայտը փակվել է | Հաճախորդը (`ticket-closed`) |

Եթե բաժնի համար էլ. փոստի հասցե կարգավորված չէ, հայտ ստեղծելիս կամ հաճախորդի պատասխանի դեպքում ծանուցում չի ուղարկվում։

## Փակել, վերաբացել, ջնջել {#close-reopen-delete}

- **Փակել** — փակում է հայտը և նամակ է ուղարկում հաճախորդին։ Փակված հայտին պատասխանել հնարավոր չէ (`TICKET_REPLY_NOT_ALLOWED`)։ Արդեն փակված հայտը կրկին փակելիս վերադարձվում է `TICKET_CLOSE_NOT_ALLOWED`։
- **Վերաբացել** — փակված հայտը վերադարձնում է «Բաց» կարգավիճակի։
- **Ջնջել** — հայտը ընդմիշտ ջնջվում է։ Դա հնարավոր չէ չեղարկել։

Հին հայտերի ավտոմատ փակում չկա։

## Բացեք հայտ հաճախորդի համար {#open-a-ticket-for-a-client}

Բացեք **Աջակցություն → Բացել նոր հայտ**։

<Steps>
<li>

Որոնեք հաճախորդին ըստ անվան, էլ. փոստի կամ ID-ի և ընտրեք նրան։ **Անուն** և **Էլ. փոստի հասցե** դաշտերը լրացվում են հաճախորդի տվյալներից։

</li>
<li>

Լրացրեք **Թեմա**, **Բաժին**, **Առաջնահերթություն** և **Հաղորդագրություն** դաշտերը։

</li>
<li>

Սեղմեք **Բացել տոմս**։

</li>
</Steps>

Հայտ կարելի է բացել նաև հաճախորդի էջի **Տոմսեր** ներդիրից։

## Պատրաստի պատասխաններ {#predefined-replies}

Բացեք **Աջակցություն → Պատրաստի պատասխաններ**։ Ենթավերնագիր՝ «Տոմսերի պատրաստի պատասխանների ձևանմուշների կառավարում»։

**Կատեգորիաներ** — պատասխանները կազմակերպում են խմբերի։ Սեղմեք **Ավելացնել կատեգորիա** և մուտքագրեք կատեգորիայի անվանումը։ Պատասխաններ կամ ենթակատեգորիաներ պարունակող կատեգորիան հնարավոր չէ ջնջել (`PREDEFINED_REPLY_CATEGORY_IN_USE`)։ Գոյություն չունեցող պատրաստի պատասխանը վերադարձնում է `PREDEFINED_REPLY_NOT_FOUND`։

**Պատասխաններ** — սեղմեք **Ավելացնել պատրաստի պատասխան** և լրացրեք Անվանում, Կատեգորիա և Բովանդակություն դաշտերը։

**Որոնում** — պատրաստի պատասխանների որոնում ըստ անվան կամ բովանդակության։

## Աջակցության հաշվետվություններ {#support-reports}

Բացեք **Հաշվետվություններ** և ընտրեք ձեզ անհրաժեշտ հաշվետվությունը.

| Հաշվետվություն | Ինչին է պատասխանում |
|--------|----------------|
| Աջակցության ակնարկ | Վեց ցուցանիշ ընտրված ժամանակահատվածի համար՝ նոր տոմսեր, հաճախորդների պատասխաններ, աշխատակիցների պատասխաններ, առանց պատասխանի տոմսեր, առաջին պատասխանի միջին ժամանակ, և ուղարկված հայտերի բաշխումն ըստ ժամերի |
| Տոմսերի թեգերի ակնարկ | Թեգերի անունները և թե քանի հայտ ունի յուրաքանչյուր թեգը՝ ընտրված ամսաթվերի միջակայքում |
| Տոմսերի գնահատականներ | Աշխատակցի միջին գնահատականը ընտրված ամսաթվերի միջակայքում |
| Հաճախորդների մեկնաբանությունները տոմսերի վերաբերյալ | Հաճախորդների թողած առանձին մեկնաբանությունները |
| Աջակցության տոմսերի պատասխաններ | Յուրաքանչյուր ադմինի մշակած հայտերի բաշխումն ընտրված ամսվա համար |

## Ինչը ներկառուցված չէ {#what-is-not-built-in}

<Callout type="note">
Հայտերը չեն ստեղծվում մուտքային նամակներից, և հին հայտերը ավտոմատ չեն փակվում։
</Callout>
