# Գործարքներ, վճարովի կետեր և գնառաջարկներ <Label type="admin" /> {#transactions-billable-items-and-quotes}

## Գործարքներ {#transactions}

Համակարգում գրանցված բոլոր ֆինանսական իրադարձությունները տեսնելու համար անցեք **Գործարքներ** բաժինը։

**Ցուցադրման զտիչ՝** ամբողջ ակտիվությունը, ստացված վճարումները, ուղարկված վճարումները։

Էկրանի վերևում ցուցադրվում են ընտրված ժամանակահատվածի **ամփոփ գումարները**՝ ընդհանուր ստացվածը, ընդհանուր ուղարկվածը և զուտ գումարը։

**Manual** նշանը ցույց է տալիս այն գործարքները, որոնք գրանցել է աշխատակիցը, այլ ոչ թե մշակվել են վճարային համակարգով։

### Գործարքի ավելացում {#add-a-transaction}

Սեղմեք **Ավելացնել գործարք**՝ հաշիվ-ապրանքագրի ընթացքից դուրս կատարված վճարում կամ դուրսգրում գրանցելու համար։

| Դաշտ | Նշումներ |
|-------|-------|
| Կապված հաճախորդ | Հաճախորդը, ում պատկանում է այս գործարքը |
| Մուտք | Ստացված գումարը |
| Ելք | Ուղարկված գումարը |
| Միջնորդավճարներ | Վճարային համակարգի կամ մշակման միջնորդավճարները |
| Գործարքի ID | Ձեր բանկի կամ վճարային համակարգի հղումը |
| Վճարման եղանակ | Ինչպես է տեղափոխվել գումարը |
| Հաշիվ-ապրանքագրերի ID-ներ (ստորակետով բաժանված) | Կապել գործարքը մեկ կամ մի քանի հաշիվ-ապրանքագրի հետ |
| Ավելացնել հաճախորդի կրեդիտային մնացորդին | Նշեք՝ զուտ գումարը կրեդիտ ավելացնելու համար |

Գործարքը պետք է ունենա մուտքի կամ ելքի գումար (`TRANSACTION_AMOUNT_REQUIRED`)։

**Ավելացնել հաճախորդի կրեդիտային մնացորդին** նշված գործարքը միաժամանակ հաճախորդի կրեդիտների պատմության տող է (տես հաճախորդի **Կրեդիտ** ներդիրը)։ Այն այլևս հնարավոր չէ խմբագրել կամ ջնջել (`TRANSACTION_CREDIT_LOCKED`). մնացորդը ուղղեք Կրեդիտ ներդիրի ճշգրտմամբ։ Կրեդիտների պատմության ներդրումից առաջ գրանցված գրառումները շարունակում են խմբագրվել և ջնջվել, իսկ ջնջելը չեղարկում է դրանց կրեդիտային շարժը։ Այս ցանկը ցույց է տալիս այն գրառումները, որոնք գումար են տեղափոխել. հաշիվ-ապրանքագրին կիրառված կամ աշխատակցի կողմից ճշգրտված կրեդիտը գումար չի տեղափոխում և երևում է միայն Կրեդիտ ներդիրում։

## Վճարովի կետեր {#billable-items}

Հաշիվ-ապրանքագրման հերթում գտնվող կետերը տեսնելու համար անցեք **Վճարովի կետեր** բաժինը։

**Կարգավիճակներ՝**

| Կարգավիճակ | Նշանակություն |
|--------|---------|
| Չհաշվարկված | Սպասում է, որ օրական առաջադրանքը այն ավելացնի հաշիվ-ապրանքագրում |
| Հաշվարկված | Արդեն ավելացված է հաշիվ-ապրանքագրում |
| Կրկնվող | Կարգավորված է կրկնվելու համար, դեռ ակտիվ չէ |
| Ակտիվ կրկնվող | Այս պահին ստեղծում է կրկնվող գանձումներ |
| Ավարտված կրկնվող | Կրկնվող շրջանն ավարտվել է |

### Վճարովի կետի ավելացում {#add-a-billable-item}

Հաճախորդի էջից սեղմեք **Ավելացնել վճարովի կետ**։

| Դաշտ | Նշումներ |
|-------|-------|
| Հաճախորդ | Հաճախորդը, ում պետք է գանձել |
| Նկարագրություն | Տողի տեքստը, որը երևում է հաշիվ-ապրանքագրում |
| Գումար | Գանձվող գումարը |
| Արժույթ | Հաշիվ-ապրանքագրի արժույթը |
| Տեսակ | Մեկանգամյա կամ կրկնվող |
| Հաշվարկել՝ | Կետը հաշիվ-ապրանքագրում ներառելու ամսաթիվը |
| Կրկնվելու պարբերություն | Շաբաթական, ամսական, եռամսյակային կամ տարեկան (միայն կրկնվող կետերի համար) |

Վճարովի կետերը հաշիվ-ապրանքագրերում ավելացնում է վճարովի կետերի օրական առաջադրանքը։ Արդեն հաշիվ-ապրանքագրում ավելացված կետը փոփոխել հնարավոր չէ (`BILLABLE_ITEM_INVOICED`)։

## Գնառաջարկներ {#quotes}

Բոլոր գնառաջարկները տեսնելու համար անցեք **Գնառաջարկներ** բաժինը։ Գնառաջարկի միջոցով հաճախորդին կարող եք ուղարկել գներով առաջարկ և ընդունվելուց հետո այն վերածել հաշիվ-ապրանքագրի։

**Փուլեր՝** սևագիր, ուղարկված, սպասման մեջ, ընդունված, կորսված, ժամկետանց, փակված։

### Գնառաջարկի ստեղծում {#create-a-quote}

Սեղմեք **Ստեղծել գնառաջարկ**։

<Steps>
<li>

Լրացրեք **Թեմա**, **Փուլ**, **Հաճախորդ** և **Վավեր է մինչև** դաշտերը։

</li>
<li>

Ավելացրեք **Առաջարկի տեքստը** (ցուցադրվում է հաճախորդին), **Նշումներ հաճախորդի համար** և **Նշումներ միայն ադմինի համար**։

</li>
<li>

Ավելացրեք տողեր՝ **Քանակ**, **Նկարագրություն**, **Միավորի գին**, **Զեղչ %**, **Հարկվող**։

</li>
<li>

Սեղմեք **Պահպանել**։

</li>
</Steps>

Գնառաջարկը կարելի է խմբագրել միայն խմբագրումը թույլ տվող փուլում (`QUOTE_NOT_EDITABLE`)։ Ընդունել կարելի է միայն համապատասխան փուլում գտնվող գնառաջարկը (`QUOTE_NOT_ACCEPTABLE`)։

### Կրկնօրինակում և փոխարկում {#duplicate-and-convert}

- **Կրկնօրինակել** — ստեղծում է գնառաջարկի պատճենը սևագիր փուլում։
- **Փոխարկել հաշիվ-ապրանքագրի** — գնառաջարկի տողերից ստեղծում է հաշիվ-ապրանքագիր։ Բուն գնառաջարկը մնում է անփոփոխ։

## Չեղարկման հայտեր {#cancellation-requests}

Հաճախորդների ներկայացրած հայտերը տեսնելու համար անցեք **Չեղարկման հայտեր** բաժինը։

Յուրաքանչյուր հայտ ցույց է տալիս ծառայությունը, հաճախորդին և տեսակը՝ **Immediate** (չեղարկել հիմա) կամ **End of Billing Period** (չեղարկել ընթացիկ ժամկետի վերջում)։

Աշխատակիցները գործում են հենց ծառայության գրառման վրա. այս էկրանը միայն ցուցադրում և ջնջում է հայտերը։

## Հաճախորդի քաղվածք {#client-statement}

Հաճախորդի գործարքների ամբողջ պատմությունը և ընթացիկ մնացորդը տեսնելու համար անցեք **Հաշվետվություններ → Client Account Register Balance**։
