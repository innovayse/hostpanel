# Языки {#languages}

<Callout type="tip">
Передавайте <code>X-Language</code>, чтобы получать сообщения на языке вашего пользователя.
</Callout>

## Заголовок X-Language {#the-x-language-header}

Передавайте нужный язык в заголовке `X-Language`. API отвечает на английском, русском и армянском.

<SettingTable :settings="[
  { name: 'X-Language', type: 'заголовок запроса', default: 'en', description: 'Код языка: en, ru или hy. Значение обрезается по краям и сравнивается без учёта регистра. Любое другое значение или отсутствие заголовка даёт язык установки по умолчанию, то есть английский, если оператор его не менял.' },
]" />

Читается только `X-Language`. `Accept-Language` игнорируется, поэтому языковая настройка браузера не влияет на вызов API.

## Что переводится {#what-is-translated}

- **Предложение ошибки.** Поле `detail` в каждом теле ошибки и предложения ошибки валидации в `errors` приходят на запрошенном языке. Код `type` не меняется никогда. Показывайте пользователю `detail`, а не `title`: заголовок большинства ошибок остаётся на английском.
- **Контент витрины.** Записи, которые оператор вводит на нескольких языках, возвращаются на запрошенном языке, а если у записи нет перевода, то на языке по умолчанию: слайды главной страницы, отзывы, партнёры, расположения серверов и проекты портфолио.

Контент, который оператор пишет только на одном языке, возвращается как есть.

## Пример {#example}

Тот же вызов с отсутствующим счётом, на армянском:

```bash
curl 'https://panel.example.com/api/me/invoices/99999999' \
  -H 'Authorization: Bearer <token>' \
  -H 'X-Language: hy'
```

```json
{
  "type": "INVOICE_NOT_FOUND",
  "title": "Not Found",
  "status": 404,
  "detail": "Այդպիսի հաշիվ-ապրանքագիր չի գտնվել։",
  "errors": null
}
```
