# Домены {#domains}

## Ваши домены {#your-domains}

<!-- See it in the demo: link goes here (#615) -->

Откройте **Мои домены**. На странице три вкладки: **Все**, **Активные** и **Истёкшие**.

Статусы доменов:

| Статус | Что он означает |
|--------|-----------------|
| Активен | Зарегистрирован и работает |
| В ожидании | Регистрация обрабатывается |
| Ожидает переноса | Идёт перенос от другого регистратора |
| Ожидает DNS | Настраивается DNS |
| Истёк | Срок домена истёк, он не активен |
| Льготный период | Срок истёк недавно. Домен ещё можно продлить по обычной цене. |
| Период выкупа | В периоде выкупа. Домен можно восстановить за повышенную плату. |
| Перенесён | Домен перенесён к другому провайдеру |
| Отменён | Регистрация домена отменена |

Пока домен регистрируется, страница показывает **Регистрация домена выполняется**. Пока идёт перенос от другого регистратора, она показывает **Перенос домена выполняется**.

## Серверы имён {#nameservers}

Откройте домен и перейдите к настройкам серверов имён. Выберите:

- **Использовать серверы по умолчанию**: используются серверы имён вашего хостинг-провайдера.
- **Использовать собственные серверы (ввести ниже)**: введите адреса собственных серверов имён.

Сохраните изменение. Изменения DNS могут вступать в силу по всему миру до 24 часов.

## Блокировка, код переноса и защита данных {#lock-transfer-code-and-privacy}

| Параметр | Что он делает |
|----------|---------------|
| Блокировка регистратора | Защищает от случайного или несанкционированного переноса; отключите её перед началом переноса к другому регистратору |
| Отправить EPP-код | Отправляет код авторизации, необходимый для переноса домена к другому регистратору |
| Защита персональных данных | Скрывает ваши личные контактные данные от публичных запросов WHOIS |

## Продление домена {#renew-a-domain}

Нажмите **Продлить сейчас**, чтобы продлить домен до истечения срока. Можно также включить **автопродление**. Когда оно включено, счёт на продление выставляется автоматически до истечения срока домена, а домен продлевается после оплаты.

## Контактные данные {#contact-details}

Откройте домен, чтобы обновить контактные данные владельца. Изменения могут потребовать подтверждения по письму от реестра.

## Входящий перенос домена {#transfer-a-domain-in}

Чтобы перенести домен от другого регистратора к этому провайдеру, воспользуйтесь поиском доменов в процессе [оформления заказа](/ru/customers/ordering), нажмите **Перенести этот домен** и введите **Код авторизации** от вашего текущего регистратора.
