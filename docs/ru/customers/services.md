# Услуги и SSH-ключи {#services-and-ssh-keys}

## Ваши услуги {#your-services}

<!-- See it in the demo: link goes here (#615) -->

Откройте **Мои услуги**. Каждая услуга показывает свой статус:

| Статус | Что он означает |
|--------|-----------------|
| В ожидании | Заказ оформлен, но услуга ещё не настроена |
| Активен | Услуга работает |
| Приостановлена | Услуга приостановлена. Пользоваться ею нельзя, пока она не будет возобновлена. |
| Завершена | Срок услуги закончился (также отображается как «Terminated») |

## Настройка новой услуги {#set-up-a-new-service}

Если услуге нужна настройка, она показывает **Требуется настройка**.

<Steps>
<li>

Нажмите **Завершить настройку** у услуги.

</li>
<li>

Пройдите шаги настройки: выберите домен, задайте учётные данные и проверьте результат.

</li>
<li>

Услуга становится активной, когда настройка завершена.

</li>
</Steps>

Настройка становится доступной, когда первый счёт оплачен полностью.

## Управление услугой {#manage-a-service}

Нажмите на услугу, чтобы открыть её. Вкладка **Обзор** показывает ваш тариф, платёжные данные и быстрые ссылки.

- **Сменить пароль**: введите новый пароль и нажмите **Сменить пароль**. Требуется право **Просмотр и изменение паролей**.
- **Войти в панель управления**: открывает панель управления вашим хостингом напрямую.
- **Запрос на отмену**: выберите **Немедленно** (отмена сразу) или **По окончании периода** (услуга работает до конца текущего периода), укажите причину и нажмите **Отправить запрос на отмену**. Требуется право **Размещение заказов**.

## SSH-ключи {#ssh-keys}

SSH-ключ представляет собой пару файлов: закрытый ключ, который остаётся на вашем компьютере, и открытый ключ, который вы добавляете на сервер. При подключении сервер проверяет, что ваш закрытый ключ соответствует открытому ключу, сохранённому на сервере. Пароль вам не нужен, а закрытый ключ никогда не покидает ваш компьютер.

Вкладка **SSH-ключи** позволяет управлять открытыми ключами вашего хостинг-аккаунта.

Чтобы видеть эту вкладку, вашему аккаунту нужно право **Просмотр и изменение паролей**.

<!-- See it in the demo: link goes here (#615) -->

### Подключение к серверу {#connect-to-your-server}

Вкладка показывает **Хост**, **Порт** и **Пользователь** для вашего аккаунта. Нажмите **Подключение**, чтобы скопировать готовую команду SSH.

### Добавление ключа {#add-a-key}

<Steps>
<li>

Откройте вкладку **SSH-ключи**. Вкладка показывает **Ваши ключи (число/максимум)**.

</li>
<li>

Прокрутите до **Добавить ключ**. Вставьте открытый ключ в поле **Открытый ключ (ED25519)** и введите **Название** (например, «Рабочий ноутбук»).

</li>
<li>

Нажмите **Добавить ключ**.

</li>
</Steps>

<Callout type="danger">
Никогда не вставляйте закрытый ключ (файл <em>без</em> .pub). Страница его отклонит, но держите эту привычку на любом сайте.
</Callout>

Принимаются только открытые ключи ED25519. Если у вас его ещё нет, руководство **Как создать SSH-ключ?** на этой же вкладке проведёт вас через создание.

### Автоматический деплой из GitHub или GitLab {#deploy-automatically-from-github-or-gitlab}

Руководство **Автоматический деплой из GitHub или GitLab** на вкладке «SSH-ключи» показывает, как настроить автоматический деплой при каждом пуше в основную ветку.

### Отзыв ключа {#revoke-a-key}

Нажмите **Отозвать** рядом с ключом, затем подтвердите в окне **Отозвать ключ?**. Ключ удаляется с сервера.

### Значки статуса ключа {#key-status-badges}

| Значок | Что он означает |
|--------|-----------------|
| Ожидает | Ключ добавляется на сервер |
| Установка не подтверждена | Ключ отправлен, но сервер не подтвердил, что он добавлен |
| Отзыв не подтверждён | Отзыв отправлен, но не подтверждён |
| Снят с сервера, пока услуга приостановлена | Ключ сохранён, но неактивен, пока услуга не будет возобновлена |
| Отозван | Ключ удалён |
| Прежний сервер | Ключ был добавлен на прежнем сервере и больше не действует |
| Не найден на сервере | Ключа нет на сервере. Нажмите «Повторить», чтобы попробовать снова. |

### Когда SSH-ключи недоступны {#when-ssh-keys-are-not-available}

| Сообщение | Что делать |
|-----------|------------|
| «Доступ по SSH отключён для этого аккаунта хостинга. Обратитесь в поддержку, чтобы включить его.» | Попросите хостинг-провайдера включить SSH для вашего аккаунта |
| «Управление SSH-ключами недоступно для этого типа хостинга.» | Этот тип хостинга не поддерживает управление SSH-ключами |
| «Управление SSH-ключами ещё не включено на сервере этой услуги.» | Сервер ещё не настроен для управления SSH-ключами. Зайдите позже или обратитесь в поддержку. |
| «SSH-ключами можно управлять, только пока услуга активна.» | Сначала возобновите услугу |
| «Не удалось связаться с сервером хостинга. Повторите попытку позже.» | Временная проблема с сетью. Повторите через минуту. |
