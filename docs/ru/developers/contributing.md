## Настройки сайта документации {#documentation-site-settings}

Сайт документации (VitePress, в `docs/`) при сборке читает две необязательные переменные окружения. У обеих есть значения по умолчанию для публичного сайта документации, поэтому большинству участников ничего задавать не нужно.

| Переменная | Значение по умолчанию | Назначение |
|---|---|---|
| `DOCS_BASE` | `/docs/` | URL-путь, по которому отдаётся сайт, с начальным и конечным слешем. Также используется в ссылке на favicon. На собственном домене укажите `/`. |
| `DOCS_SITE_URL` | `https://hostpanel.innovayse.com/docs` | Публичный origin вместе с базовым путём, без конечного слеша. Используется в канонических ссылках, в URL изображений для предпросмотра в соцсетях и в карте сайта (`sitemap.xml` по базовому пути). Держите значение согласованным с `DOCS_BASE`. |

Например, чтобы собрать копию, которая отдаётся с корня вашего домена:

```bash
DOCS_BASE=/ DOCS_SITE_URL=https://docs.example.org npm run build
```
