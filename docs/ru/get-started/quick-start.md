# Быстрый старт {#quick-start}

Эта страница проведёт вас от чистого Linux-сервера до первого хостинг-аккаунта, который Hostpanel создаст для клиента. Каждый шаг короткий, а за подробностями есть ссылка на полное руководство.

## Что понадобится {#what-you-need}

- Linux-сервер с Docker и плагином Compose v2 и два DNS-имени, указывающих на него: одно для клиентского портала, другое для панели администратора. Полный список в разделе [Перед началом](/ru/operators/install#before-you-start).
- Сервер с панелью управления, на котором будут жить аккаунты, и его API-доступ. Аккаунты автоматически создают модули cPanel, Plesk и CWP7, см. [Серверы и группы серверов](/ru/servers/servers).
- Адрес электронной почты для учётной записи администратора.

## 1. Установите Hostpanel {#1-install-hostpanel}

Запустите установщик на сервере:

```bash
curl -fsSL https://raw.githubusercontent.com/innovayse/hostpanel/main/install.sh | bash
```

Он спросит домен портала, домен панели администратора и почту администратора, запустит стек и дождётся `/health`. В конце он выведет оба адреса и одноразовый токен настройки. Сохраните токен для следующего шага. Флаги, установка за собственным TLS-прокси и ручная установка через docker compose описаны в разделе [Установка Hostpanel](/ru/operators/install).

## 2. Создайте первого администратора {#2-create-the-first-administrator}

Откройте адрес панели администратора. Пока роль администратора никому не принадлежит, показывается экран **Начальная настройка**. Создайте учётную запись, вставьте токен настройки и нажмите **Получить роль администратора**. Если токен потерян, в разделе [Первый запуск](/ru/operators/install#first-run) показано, как прочитать его в журнале API.

## 3. Настройте почту {#3-set-up-mail}

Установщик намеренно оставляет `SMTP_HOST` пустым. Пока вы не укажете настоящий релей в `.env` и не перезапустите стек, письма подтверждения, сброса пароля и счетов не отправляются. См. [Настройка почты](/ru/operators/install#set-up-mail).

## 4. Проверьте валюту {#4-check-the-currency}

Откройте **Настройки → Валюты**. Цены можно получить, только если задана базовая валюта, иначе API отвечает `BASE_CURRENCY_NOT_CONFIGURED`. Если в списке нет базовой валюты, добавьте свою и сделайте её базовой. См. [Валюты, продления и задания](/ru/staff/currencies).

## 5. Добавьте сервер {#5-add-a-server}

<Steps>
<li>

Откройте **Серверы** и нажмите **Добавить новый сервер**.

</li>
<li>

На вкладке «Основное» введите название, имя хоста и IP-адрес. На вкладке «Подробности» выберите модуль и введите доступ: для cPanel пользователя WHM и API-токен, для CWP7 и Plesk хеш доступа.

</li>
<li>

Сохраните и нажмите **Проверить соединение** в строке сервера. Значок должен показать «Онлайн».

</li>
</Steps>

Для cPanel сначала создайте API-токен в WHM, как описано в разделе [Серверы cPanel](/ru/servers/cpanel). Если вы используете больше одного модуля, для заказов продукта нужна группа серверов, см. [Группы серверов](/ru/servers/servers#server-groups).

## 6. Создайте продукт {#6-create-a-product}

Откройте **Настройки → Продукты → Создать продукт**. Выберите тип «Общий хостинг», группу продуктов, название и slug. В поле **Название пакета** укажите точное название пакета, существующего на сервере, и заполните цену в базовой валюте хотя бы для одного периода оплаты. Пустая цена делает продукт непродаваемым на этом периоде. Не отмечайте **Скрыт**, чтобы клиенты могли его заказать. Вся форма описана в разделе [Продукты и цены](/ru/staff/products).

## 7. Включите способ оплаты {#7-turn-on-a-payment-method}

В Hostpanel встроен банковский перевод, а каждый онлайн-шлюз приходит из плагина. Для первой проверки достаточно банковского перевода. Откройте **Интеграции**, категория **Платёжные шлюзы**, нажмите **Настроить →** на карточке «Банковский перевод», заполните хотя бы один реквизит, сохраните и включите его. Клиентам банковский перевод предлагается, только пока он включён и заполнен хотя бы один реквизит. Подробности и путь через плагины в разделе [Платёжные шлюзы](/ru/payments/gateways).

## 8. Сделайте тестовый заказ {#8-place-a-test-order}

Откройте клиентский портал, закажите продукт и оформите заказ с оплатой банковским переводом, см. [Заказ](/ru/customers/ordering). Затем в панели администратора откройте **Биллинг**, **Ожидающие банковские переводы** и нажмите **Подтвердить**. Счёт оплачен, заказ выполнен.

## 9. Создайте услугу {#9-provision-the-service}

Оплаченный заказ создаёт услугу в статусе **В ожидании**. Хостинг-аккаунт в этот момент Hostpanel не создаёт. Сделайте одно из двух:

- В клиентском портале клиент открывает услугу и завершает настройку. Она доступна после полной оплаты первого счёта.
- В панели администратора откройте услугу и нажмите **Создать** в карточке «Команды модуля».

Когда панель подтвердит операцию, услуга станет **Активной**, а клиент получит письмо `service-provisioned`. Если что-то пошло не так, код ошибки объяснён в разделе [Провижининг](/ru/servers/provisioning).
