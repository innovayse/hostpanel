# Объявления, база знаний и загрузки <Label type="admin" /> {#announcements-knowledge-base-and-downloads}

## Объявления {#announcements}

Откройте **Поддержка → Объявления**. Подзаголовок: «Управление объявлениями для клиентов».

**Столбцы:** Дата, Заголовок, Опубликовано.

Нажмите **Добавить новое объявление** и заполните форму:

| Поле | Примечания |
|------|------------|
| Заголовок | Заголовок объявления |
| Объявление | Текст объявления |
| Опубликовано | Отметьте, чтобы показывать это объявление в клиентском портале |

**Дата** устанавливается автоматически и при редактировании отображается только для чтения.

В клиентском портале видны только опубликованные объявления. Если объявления не существует, возвращается `ANNOUNCEMENT_NOT_FOUND`.

Клиенты читают объявления в разделе **Объявления** клиентского портала.

## База знаний {#knowledge-base}

Откройте **Поддержка → База знаний**. Подзаголовок: «Управление статьями и категориями базы знаний».

### Категории {#categories}

Нажмите **Добавить категорию** и укажите:
- **Название категории**
- **Отметьте, чтобы скрыть**: скрывает категорию в клиентском портале
- **Описание**: показывается на странице категории

Категорию, в которой есть подкатегории, удалить нельзя (`KBCATEGORY_IN_USE`). Если категории не существует, возвращается `KBCATEGORY_NOT_FOUND`.

### Статьи {#articles}

Нажмите **Добавить статью** и заполните:
- **Заголовок**
- **Категория**
- **Содержание**
- **Опубликовано**: отметьте, чтобы статья была видна клиентам

Если статьи не существует, возвращается `KBARTICLE_NOT_FOUND`.

### Обзор {#browse}

На главной странице базы знаний есть **Обзор по категориям** и **Обзор по тегам**. Теги берутся из статей, и управлять ими напрямую нельзя.

Клиенты читают базу знаний в разделе **База знаний** клиентского портала.

## Загрузки {#downloads}

Откройте **Поддержка → Загрузки**. Подзаголовок: «Управление загружаемыми файлами и категориями».

### Категории {#categories-1}

Нажмите **Добавить категорию** и введите название категории. Категорию, в которой есть файлы или подкатегории, удалить нельзя (`DOWNLOAD_CATEGORY_IN_USE`). Если категории не существует, возвращается `DOWNLOAD_CATEGORY_NOT_FOUND`.

### Файлы {#files}

Нажмите **Добавить загрузку** и заполните форму:

| Поле | Примечания |
|------|------------|
| Тип | ZIP-файл, Исполняемый файл, PDF или Другое |
| Заголовок | Название, которое видят клиенты |
| Описание | Краткое описание |
| Имя файла | Имя файла, который отдаётся клиенту |
| Категория | Категория, к которой относится загрузка |
| Только для клиентов | Ограничивает скачивание вошедшими клиентами |
| Загрузка по продукту | Для доступа нужно купить продукт или дополнение |
| Скрыт | Убирает загрузку из клиентской зоны |

Если загрузки не существует, возвращается `DOWNLOAD_NOT_FOUND`.

<Callout type="note">
Загрузки настраиваются здесь, но в клиентском портале пока не отображаются.
</Callout>
