# Клиенты, пользователи и контакты <Label type="admin" /> {#clients-users-and-contacts}

## Список клиентов {#the-client-list}

Откройте **Клиенты** в главном меню, чтобы увидеть все аккаунты клиентов.

**Фильтры:** Имя клиента / название компании, Адрес электронной почты, Номер телефона, Статус.

**Столбцы:** ID, Имя, Почта, Компания, 2FA, Дата регистрации, Статус. Значок **Пользователь удалён** появляется, когда соответствующая учётная запись пользователя удалена.

**Статусы клиентов**

| Статус | Что блокируется |
|--------|-----------------|
| Активно | Ничего не блокируется |
| Неактивно | Нельзя оформлять новые заказы и входить |
| Приостановлено | Нельзя оформлять заказы, платить онлайн и менять данные аккаунта |
| Закрыто | Аккаунт закрыт навсегда; никакие действия недоступны |

## Добавление клиента {#add-a-client}

Откройте **Клиенты → Добавить нового клиента**.

<Steps>
<li>

**Владелец аккаунта** — выберите **Создать нового пользователя**, чтобы создать новую учётную запись для входа, или **Связать с существующим пользователем**, чтобы привязать карточку клиента к пользователю, у которого уже есть аккаунт.

</li>
<li>

**Данные профиля** — имя, фамилия, название компании, номер телефона.

</li>
<li>

**Адрес и оплата** — почтовый адрес, город, область, почтовый индекс, страна, **Валюта** (нельзя изменить после выставления клиенту счёта), **Способ оплаты** и **Контакт по оплате**.

</li>
<li>

**Уведомления по почте** — выберите, какие системные письма получает этот клиент.

</li>
<li>

**Настройки** — отметьте нужные параметры:

- **Уведомления о просрочке** — отправлять письма о просроченной оплате
- **Освобождён от налога** — в его счетах нельзя указать ставку налога
- **Отдельные счета** — по одному счёту на каждую строку заказа
- **Отключить обработку карт** — не списывать деньги с карты автоматически
- **Согласие на маркетинговые письма** — включать в маркетинговые рассылки
- **Обновление статуса** — уведомлять клиента об изменении статуса услуг
- **Разрешить единый вход (SSO)** — разрешить вход через SSO для этого аккаунта

</li>
<li>

**Заметки администратора** — личные заметки, видимые только сотрудникам.

</li>
<li>

Нажмите **Создать клиента**.

</li>
</Steps>

<Callout type="warning">
После того как клиенту выставлен счёт, его валюту изменить нельзя (<code>CLIENT_CURRENCY_ALREADY_INVOICED</code>). Выбирайте её внимательно при создании аккаунта.
</Callout>

## Сводка по клиенту {#the-client-summary}

Откройте клиента и нажмите **Сводка**. На странице показано:

- **Информация о клиенте** — контактные и платёжные данные с первого взгляда.
- **Дополнительная информация** — настройки аккаунта и заметки.
- **Счета / Биллинг** — счётчики счетов и финансовые итоги: валовая выручка, расходы клиента, чистый доход, кредитный баланс.
- **Продукты / Услуги** — активные и прошлые услуги.
- **Последние письма** — несколько последних писем, отправленных клиенту.
- **Заметки администратора** — заметки только для сотрудников.
- **Текущие предложения** — открытые коммерческие предложения.

Быстрые ссылки в правом верхнем углу: **Создать счёт**, **Добавить оплачиваемую позицию**, **Создать новое предложение**, **Открыть новый тикет**.

## Профиль {#profile}

Нажмите **Профиль**, чтобы изменить контактные данные клиента, платёжный адрес, валюту, способ оплаты и настройки аккаунта. Нажмите **Сохранить изменения**, чтобы применить их.

## Пользователи аккаунта клиента {#users-of-a-client-account}

Откройте вкладку **Пользователи**. У каждого аккаунта клиента есть один **Владелец** и могут быть дополнительные **Пользователи**.

- **+ Добавить пользователя** — выберите **Найти существующего**, чтобы привязать пользователя, у которого уже есть учётная запись, или **Пригласить по почте**, чтобы отправить приглашение.
- **Передача владения** — передайте роль владельца другому пользователю аккаунта.
- **Удалить** — удалите пользователя из аккаунта.

Владельца нельзя удалить, пока владение не передано другому (`CLIENT_OWNER_CANNOT_BE_REMOVED`). Нельзя передать владение тому, кто уже является владельцем (`CLIENT_TRANSFER_SAME_OWNER`).

## Контакты {#contacts}

Откройте вкладку **Контакты**, чтобы управлять дополнительными контактами клиента. Контакты получают копии писем, но войти в систему не могут.

- **Добавить** — заполните форму контакта и сохраните.
- **Изменить** — обновите существующий контакт.
- **Удалить** — удалите контакт навсегда.

У двух контактов одного аккаунта клиента не может быть одинакового адреса электронной почты (`CONTACT_EMAIL_IN_USE`).

## Все пользователи {#all-users}

Откройте **Клиенты → Управление пользователями**, чтобы увидеть всех пользователей всех аккаунтов клиентов. На этом экране можно:

- **Отправить письмо для сброса пароля** — отправляет ссылку для сброса на адрес электронной почты пользователя. <Label type="local" /> Только для локальных аккаунтов; для SSO-пользователей недоступно.
- **Сменить пароль** — задать новый пароль напрямую. <Label type="local" /> Только для локальных аккаунтов.

## Приостановка, деактивация и закрытие {#suspend-deactivate-and-close}

| Действие | Когда разрешено | Ошибка, если не разрешено |
|----------|-----------------|---------------------------|
| Приостановить | Активно или Неактивно | `CLIENT_SUSPEND_NOT_ALLOWED` |
| Деактивировать | Любой статус, кроме «Приостановлено» и «Закрыто» (для «Неактивно» ничего не происходит) | `CLIENT_DEACTIVATE_NOT_ALLOWED` |
| Активировать | Неактивно или Приостановлено | `CLIENT_ACTIVATE_NOT_ALLOWED` |
| Закрыть | Активно, Неактивно или Приостановлено | `CLIENT_CLOSE_NOT_ALLOWED` |

Закрытый аккаунт нельзя открыть заново через панель администратора (`CLIENT_ACTIVATE_NOT_ALLOWED`).
