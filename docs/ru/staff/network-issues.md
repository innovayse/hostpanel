# Сетевые проблемы <Label type="admin" /> {#network-issues}

Сетевые проблемы позволяют сообщать клиентам о сбоях и плановых работах.

## Список {#the-list}

Откройте **Поддержка → Сетевые проблемы**. Подзаголовок: «Управление статусом сети и отчётами об инцидентах».

Три вкладки:

| Вкладка | Что показывает |
|---------|----------------|
| Открытые | Проблемы со статусом «Сообщено» или «Расследуется» |
| Запланированные | Проблемы со статусом «Запланировано» |
| Решённые | Проблемы со статусом «Решено» |

Если проблемы не существует, возвращается `NETWORKISSUE_NOT_FOUND`.

## Сообщить о проблеме {#report-an-issue}

Нажмите **(+) Создать** и заполните форму:

| Поле | Варианты |
|------|----------|
| Заголовок | Заголовок проблемы |
| Тип | Сервер, Другое |
| Сервер | Название сервера (необязательно) |
| Приоритет | Низкий, Средний, Высокий, Критический |
| Дата начала | Когда началась проблема |
| Описание | Подробности о проблеме |

Новые проблемы всегда создаются со статусом **Сообщено**. Нажмите **Создать проблему**, чтобы сохранить.

## Обновить проблему {#update-an-issue}

Нажмите на проблему, чтобы изменить её. В форме редактирования появляются ещё два поля:

| Поле | Примечания |
|------|------------|
| Статус | Сообщено, Расследуется, Запланировано, Решено |
| Дата окончания | Когда проблема закончилась или когда ожидается её окончание |

## Плановые работы {#planned-maintenance}

<Steps>
<li>

Нажмите **(+) Создать** и заполните Заголовок, Тип, Приоритет, Дату начала и Описание. Сохраните со статусом **Сообщено**.

</li>
<li>

Откройте проблему, установите **Статус** «**Запланировано**» и укажите **Дату окончания**.

</li>
<li>

Когда работы завершены, снова отредактируйте проблему и установите **Статус** «**Решено**».

</li>
</Steps>

## Что видят клиенты {#what-customers-see}

Сетевые проблемы пока не отображаются в клиентском портале.
