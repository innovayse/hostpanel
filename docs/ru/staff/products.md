# Продукты и цены <Label type="admin" /> {#products-and-pricing}

<DemoLink path="/settings/products" />

Открытие несуществующего продукта возвращает `PRODUCT_NOT_FOUND`. Заказ продукта, который не активен, возвращает `PRODUCT_NOT_AVAILABLE`. Если базовая валюта не настроена, запросы цен возвращают `BASE_CURRENCY_NOT_CONFIGURED`.

## Как организованы продукты {#how-products-are-organised}

Продукты объединяются в **группы продуктов**. У каждой группы есть название, описание и статус «Активно» или «Неактивно». Экрана для создания и редактирования групп продуктов пока нет; группы создаёт начальная миграция данных и заполняет их при чистой установке.

Продукты одной группы отображаются на витрине вместе.

## Экран «Продукты» {#the-products-screen}

Откройте **Настройки → Продукты**. Подзаголовок: «Управление тарифами хостинга и услугами, доступными для покупки».

**Столбцы:** Название, Группа, Тип, Цена за месяц, Цена за год (обе в базовой валюте), счётчик «+» с числом других валют, в которых указана цена продукта, и Статус.

## Типы продуктов {#product-types}

| Тип | Что он представляет |
|-----|---------------------|
| Общий хостинг | Тариф общего веб-хостинга |
| VPS | Виртуальный частный сервер |
| Выделенный | Выделенный сервер |
| Email | Почтовые ящики и почтовый хостинг |
| Дополнение | Доп. опция, привязанная к другой услуге |
| Резервное копирование | Хранилище резервных копий и восстановление |
| Цифровой | Лицензия, пакет кредитов или цифровой товар, который выдаёт плагин выдачи |
| Другое | Любая другая или нестандартная услуга |

<Callout type="note">
«Домен» и «SSL» не предлагаются как карточки типов в форме создания. Цены на домены настраиваются на <a href="/ru/staff/tld-pricing">экране цен на TLD</a>, а SSL-продукты создаются с типом «Другое».
</Callout>

## Создание продукта {#create-a-product}

Откройте **Настройки → Продукты → Создать продукт** и заполните форму.

<Steps>
<li>

**Тип продукта** — выберите карточку типа, которая соответствует услуге.

</li>
<li>

**Группа продуктов** — выберите группу, к которой относится продукт. Если такой группы ещё нет, пока её можно создать через API (`PRODUCT_GROUP_NOT_FOUND`).

</li>
<li>

**Название продукта** — название, которое видят клиенты.

</li>
<li>

**Slug (URL)** — путь URL страницы продукта на витрине (например, `/products/starter`).

</li>
<li>

**Название пакета** — хостинг-пакет, который используется при создании аккаунта на сервере. Обязателен для типов с провижинингом; для типов «Дополнение», «Цифровой» и «Другое» оставьте пустым (`PRODUCT_PACKAGE_MISSING`, если провижинер его ожидает, а он не задан).

</li>
<li>

**Группа серверов** — группа серверов, которую может использовать провижинер. Вариант «Нет (автовыбор по модулю)» позволяет модулю выбрать самому. См. [Серверы и провижининг](/ru/servers/provisioning).

</li>
<li>

**Описание** — краткое описание, которое показывается на витрине.

</li>
<li>

**Порядок сортировки** — позиция внутри группы, от меньшего к большему. Продукты с одинаковым числом сортируются по названию.

</li>
<li>

**Рекомендуемый тариф** — отметьте, чтобы на витрине показывалась пометка «Рекомендуем». В группе может быть только один рекомендуемый продукт; сохранение снимает пометку с остальных.

</li>
<li>

**Артикул (SKU)** — необязательный уникальный код, по которому плагины выдачи опознают продукт (буквы, цифры, дефисы, подчёркивания или точки; не более 64 символов).

</li>
<li>

**Метаданные** — необязательный объект JSON, который передаётся плагину выдачи (не более 16 КБ).

</li>
<li>

**Льготный период (дней)** — сколько дней услуга остаётся доступной после срока оплаты, прежде чем будет приостановлена.

</li>
<li>

**Скрыт** — отметьте, чтобы сделать продукт неактивным и скрыть его из формы заказа. Неактивный продукт заказать нельзя (`PRODUCT_NOT_AVAILABLE`).

</li>
<li>

Нажмите **Создать продукт**.

</li>
</Steps>

## Периоды оплаты и цены по валютам {#billing-cycles-and-prices-per-currency}

Таблица цен входит в форму продукта. В ней одна строка на каждую включённую валюту. В каждой строке показано:

| Столбец | Значение |
|---------|----------|
| Включена | Предлагается ли эта валюта для данного продукта |
| Валюта | Код валюты; базовая валюта помечена «Базовая» |
| Ежемесячно | Цена за месяц |
| Ежеквартально | Цена за три месяца |
| Раз в полгода | Цена за шесть месяцев |
| Ежегодно | Цена за год |
| Раз в два года | Цена за два года |

<Callout type="warning">
Пустая цена делает продукт недоступным для продажи на этом периоде в этой валюте. Попытка заказать такой продукт возвращает <code>ORDER_PRODUCT_PRICE_UNAVAILABLE</code>.
</Callout>

Поля платы за подключение нет. Клиенты, которым счета выставляются не в базовой валюте, платят ту цену, которую вы указали для этой валюты, напрямую: курсы обмена к ценам продуктов не применяются.

Кнопка **Обновить цены товаров** на экране «Валюты» открывает окно, где вы выбираете, для каких валют пересчитать цены. Цены продуктов в выбранных валютах перезаписываются пересчётом из базовой валюты по сохранённому курсу обмена.

## Что можно изменить после создания {#what-you-can-change-after-creation}

Название, описание, slug, название пакета, порядок сортировки, признак рекомендуемого, признак скрытого и цены можно менять в любое время. Тип и группу продукта после создания изменить нельзя.

## Спецификация тарифа {#the-plan-specification}

В списке продуктов откройте меню действий строки нужного продукта и нажмите **Редактировать спецификацию**, чтобы открыть диалог «Спецификация».

- **Добавить строку** — введите название характеристики и её значение.
- **Удалить строку** — нажмите кнопку удаления в строке.

Названия характеристик выстраиваются в таблице сравнения по продуктам, поэтому одну и ту же характеристику во всех продуктах пишите одинаково. Название может встречаться в продукте только один раз; дубликат отклоняется (`PRODUCT_FEATURE_LABEL_DUPLICATE`). Таблица сравнения на витрине остаётся скрытой, пока хотя бы у одного продукта в группе нет строки спецификации.

## Рекомендуемые и скрытые продукты {#recommended-and-hidden-products}

- **Рекомендуемый** — пометку «Рекомендуем» может иметь только один продукт в группе. Установка её на продукт снимает её со всех остальных в той же группе.
- **Скрыт** — делает продукт неактивным и убирает его из формы заказа на витрине. Неактивный продукт никто заказать не может (`PRODUCT_NOT_AVAILABLE`).

## Комплекты продуктов {#product-bundles}

**Комплект продуктов** продаёт несколько продуктов вместе как одно предложение: например, тариф хостинга с почтовым ящиком, при желании с регистрацией домена и со скидкой. Комплект — это шаблон заказа: клиент заказывает комплект, а в заказе оказывается по одной строке на каждый продукт и строка домена, если комплект включает домен.

Откройте **Настройки → Комплекты продуктов**. В списке показаны название каждого комплекта, его продукты, включённый домен, скидка и статус.

### Из чего состоит комплект {#what-a-bundle-is-made-of}

- **Продукты** — один или несколько продуктов каталога. Ровно один из них — **основной продукт**: он нужен комплекту, и только один. Продукт может входить в комплект только один раз. Продукт-домен компонентом быть не может (`PRODUCT_BUNDLE_DOMAIN_PRODUCT_NOT_ALLOWED`).
- **Регистрация домена** — необязательна и компонентом не является. Цена домена зависит от зоны (TLD), которую выберет клиент, поэтому комплект хранит лишь то, что регистрация включена, и на сколько **лет** (от 1 до 10). Имя домена клиент выбирает при заказе, а срок регистрации всегда берётся из комплекта: клиент не может ни сократить его, ни купить более длинный по цене комплекта. Строка домена оценивается по <a href="./tld-pricing">ценам на TLD</a> при оформлении заказа.
- **Скидка** — см. ниже.

### Создание комплекта {#create-a-bundle}

Откройте **Настройки → Комплекты продуктов → Создать комплект** и заполните форму.

<Steps>
<li>

**Название** и **Описание** — то, что клиент видит у комплекта. Название обязательно.

</li>
<li>

**Порядок сортировки** — позиция в списке, от меньшего к большему.

</li>
<li>

**Продукты** — нажмите **Добавить продукт**, выберите продукт из списка и повторите для каждого продукта. Переключателем в строке отметьте **основной продукт**. Продукт, уже выбранный в другой строке, повторно не предлагается.

</li>
<li>

**Включает регистрацию домена** — включите, чтобы добавить домен, затем укажите **Лет регистрации**.

</li>
<li>

**Скидка** — выберите тип и, если это не «Без скидки», размер.

</li>
<li>

Нажмите **Сохранить**. Новый комплект создаётся активным.

</li>
</Steps>

При редактировании комплекта появляется переключатель **Активно**. Сохранение заменяет данные и продукты комплекта. Если сохранение отклонено, причина показывается в диалоге, например `PRODUCT_BUNDLE_PRIMARY_INVALID` (основных продуктов не ровно один), `PRODUCT_BUNDLE_ITEM_DUPLICATE` (продукт указан дважды), `PRODUCT_BUNDLE_ITEMS_REQUIRED` (нет ни одного продукта), `PRODUCT_BUNDLE_DOMAIN_TERM_INVALID` (срок не подходит) или `PRODUCT_BUNDLE_DISCOUNT_INVALID` (тип, размер и валюта скидки не согласуются).

### Типы скидки {#discount-types}

| Тип | Значение |
|-----|----------|
| Без скидки | Комплект стоит столько, сколько стоят его части |
| Процент | Процент от 0 до 100 |
| Фиксированная сумма | Фиксированная сумма в выбранной вами валюте — валюте скидки |

### Как применяется скидка {#how-the-discount-is-applied}

- Скидка вычитается из строк заказа при его оформлении, включая строку домена, поэтому заказ, его счёт и создаваемые услуги несут одну итоговую цену.
- **Процент** вычитается из каждой строки. **Фиксированная сумма** распределяется по строкам пропорционально их ценам; доли округляются нарастающим итогом до наименьшей единицы валюты, поэтому скидки по строкам в сумме дают общую скидку точно. Скидка ограничена суммой заказа, поэтому строка никогда не уходит ниже нуля. Если клиенту выставляются счета не в валюте скидки, фиксированная сумма сначала пересчитывается по сохранённому курсу обмена.
- Скидка комплекта применяется **поверх** скидки группы клиентов: цены, с которыми она работает, уже учитывают скидку группы, поэтому клиент из группы со скидкой сохраняет её и внутри комплекта.
- Налог считается с уже уменьшенной строки.
- Строки счёта называют комплект: описание каждой строки заканчивается названием комплекта в скобках.

### Неактивные комплекты, удаление и заказы {#inactive-bundles-deleting-and-orders}

Неактивный комплект скрыт на витрине, и заказать его нельзя (`PRODUCT_BUNDLE_NOT_AVAILABLE`). Удаление комплекта не затрагивает оформленные по нему заказы: они сохраняются, но теряют связь с комплектом. Экран заказа показывает **Комплект продуктов**, по которому оформлен заказ, пока этот комплект существует.

## Пока недоступно {#not-available-yet}

**Дополнения к услугам** и **Акции** — это экраны-заглушки, они не работают.
