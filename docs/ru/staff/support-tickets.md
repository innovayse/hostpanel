# Тикеты поддержки <Label type="admin" /> {#support-tickets}

## Отделы {#departments}

При чистой установке создаются четыре отдела. Адреса для связи с ними читаются из этих настроек при первом запуске:

<SettingTable :settings="[
  { name: 'DEPARTMENT_SUPPORT_EMAIL', type: 'string', default: 'support@example.com', description: 'Адрес электронной почты отдела технической поддержки' },
  { name: 'DEPARTMENT_BILLING_EMAIL', type: 'string', default: 'billing@example.com', description: 'Адрес электронной почты отдела биллинга' },
  { name: 'DEPARTMENT_SALES_EMAIL', type: 'string', default: 'sales@example.com', description: 'Адрес электронной почты отдела продаж' },
  { name: 'DEPARTMENT_GENERAL_EMAIL', type: 'string', default: 'hello@example.com', description: 'Адрес электронной почты общего отдела' },
]" />

Эти настройки читаются только один раз, когда таблица отделов пуста.

<Callout type="note">
Экрана администратора для создания и редактирования отделов пока нет. В API для этого есть конечные точки. Если тикет ссылается на отдел, которого больше нет, возвращается <code>DEPARTMENT_NOT_FOUND</code>.
</Callout>

## Статусы и приоритеты тикетов {#ticket-statuses-and-priorities}

| Статус | Что он означает |
|--------|-----------------|
| Открыт | Тикет открыт и ждёт ответа сотрудника |
| Ожидает ответа | Сотрудник ответил; ждём клиента |
| Закрыт | Тикет закрыт |

**Приоритеты:** Низкий, Средний, Высокий.

## Список тикетов {#the-ticket-list}

Откройте **Поддержка → Тикеты поддержки**. Подзаголовок: «Управление всеми обращениями клиентов в поддержку».

**Фильтры:** Все активные тикеты, Помеченные, Открытые, Ожидают ответа, Закрытые.

**Поиск:** по теме тикета.

**Столбцы:** Тема, Отдел, Инициатор, Статус, Последний ответ.

**Массовые действия** (в списке «С выбранными:»): Закрыть, Удалить, Пометить, Снять пометку.

<Callout type="warning">
Удаление тикета нельзя отменить.
</Callout>

Если тикета не существует, возвращается `TICKET_NOT_FOUND`.

## Ответ на тикет {#answer-a-ticket}

Нажмите на тикет, чтобы открыть его страницу.

**Панель «Настройки тикета»** (справа): Отдел, Приоритет, Статус, Сохранить изменения.

**Переписка**: цепочка сообщений между клиентом и сотрудниками.

<Steps>
<li>

Введите ответ в поле **Добавить ответ**.

</li>
<li>

Нажмите **Ответить**, чтобы отправить его.

</li>
</Steps>

**Кто получает уведомления по почте:**

| Событие | Получатель |
|---------|------------|
| Тикет создан | Адрес электронной почты отдела (`ticket-created`) |
| Отвечает сотрудник | Клиент (`ticket-replied`) |
| Отвечает клиент | Адрес электронной почты отдела (`ticket-replied`) |
| Тикет закрыт | Клиент (`ticket-closed`) |

Если у отдела не настроен адрес электронной почты, при создании тикета и ответе клиента уведомление не отправляется.

## Закрытие, повторное открытие, удаление {#close-reopen-delete}

- **Закрыть**: закрывает тикет и отправляет клиенту письмо. В закрытый тикет нельзя добавлять ответы (`TICKET_REPLY_NOT_ALLOWED`). Попытка закрыть уже закрытый тикет возвращает `TICKET_CLOSE_NOT_ALLOWED`.
- **Открыть снова**: переводит закрытый тикет обратно в статус «Открыт».
- **Удалить**: удаляет тикет навсегда. Это нельзя отменить.

Старые тикеты автоматически не закрываются.

## Открыть тикет для клиента {#open-a-ticket-for-a-client}

Откройте **Поддержка → Открыть новый тикет**.

<Steps>
<li>

Найдите клиента по имени, адресу электронной почты или ID и выберите его. Поля **Имя** и **Адрес электронной почты** заполняются из карточки клиента.

</li>
<li>

Заполните **Тема**, **Отдел**, **Приоритет** и **Сообщение**.

</li>
<li>

Нажмите **Открыть тикет**.

</li>
</Steps>

Тикет также можно открыть на вкладке **Тикеты** самого клиента.

## Готовые ответы {#predefined-replies}

Откройте **Поддержка → Готовые ответы**. Подзаголовок: «Управление шаблонами готовых ответов на тикеты».

**Категории**: группируйте ответы. Нажмите **Добавить категорию** и введите название категории. Категорию, в которой есть ответы или подкатегории, удалить нельзя (`PREDEFINED_REPLY_CATEGORY_IN_USE`). Если готового ответа не существует, возвращается `PREDEFINED_REPLY_NOT_FOUND`.

**Ответы**: нажмите **Добавить готовый ответ** и заполните Название, Категорию и Содержание.

**Поиск**: ищите готовые ответы по названию или содержанию.

## Отчёты по поддержке {#support-reports}

Откройте **Отчёты** и выберите нужный отчёт:

| Отчёт | На какой вопрос отвечает |
|-------|--------------------------|
| Обзор поддержки | Шесть показателей за выбранный период: новые тикеты, ответы клиентов, ответы сотрудников, тикеты без ответа, среднее время первого ответа и разбивка тикетов по часам подачи |
| Обзор тегов тикетов | Названия тегов и число тикетов с каждым тегом за выбранный период |
| Оценки по тикетам | Средняя оценка по каждому сотруднику за выбранный период |
| Комментарии клиентов к тикетам | Отдельные комментарии, оставленные клиентами |
| Ответы на тикеты поддержки | Разбивка обработанных тикетов по администраторам за выбранный месяц |

## Чего нет в системе {#what-is-not-built-in}

<Callout type="note">
Тикеты не создаются из входящей почты, а старые тикеты не закрываются автоматически.
</Callout>
