# Доменные зоны и регистраторы <Label type="admin" /> {#domain-extensions-and-registrars}

<DemoLink path="/settings/tld-pricing" />

## Регистраторы {#registrars}

В Hostpanel входят два рабочих провайдера-регистратора. Настройте их в разделе **Интеграции**, категория **Регистраторы доменов**.

### Регистратор общих доменов {#general-domain-registrar}

Занимается регистрацией и управлением распространёнными международными зонами (.com, .net, .org и другими).

**Настройки:**

| Поле | Обязательное | Секретное |
|------|--------------|-----------|
| Ключ API | Да | Да |
| API Username | Да | Нет |
| IP клиента из белого списка | Да | Нет |

Прежде чем интеграцию можно будет включить, нужно заполнить все три поля.

### Регистратор национальных доменов {#country-code-domain-registrar}

Занимается регистрацией и управлением зонами национальных доменов `.am`.

**Настройки:**

| Поле | Обязательное | Секретное |
|------|--------------|-----------|
| Электронная почта аккаунта | Да | Нет |
| Пароль аккаунта | Да | Да |
| URL API | Нет | Нет |
| Тестовый режим | Нет | Нет |

Прежде чем интеграцию можно будет включить, нужно заполнить электронную почту и пароль аккаунта. Во время настройки используйте тестовый режим, чтобы не создавать настоящих регистраций.

<Callout type="note">
В списке интеграций также есть записи других провайдеров-регистраторов, для которых нет рабочей реализации. Не настраивайте их и не полагайтесь на них.
</Callout>

<Callout type="danger">
Никогда не помещайте учётные данные регистратора на скриншоты и в общие документы. Ключи API и пароли дают полный доступ к аккаунту.
</Callout>

### Проверка соединения с регистратором {#test-the-registrar-connection}

На странице интеграции регистратора, который поддерживает проверку соединения, нажмите **Проверить соединение**. Панель **Состояние соединения** показывает:

- **Соединение в порядке** — учётные данные верны, API регистратора доступен.
- **Соединение не удалось** — проверьте учётные данные и IP-адрес из белого списка.

Панель также показывает **Конечную точку**, к которой обращался клиент, и **Время отклика**.

Если регистратор не настроен, при попытке выполнить операцию с доменом возвращается `REGISTRAR_NOT_CONFIGURED`.

## Экран «Цены на TLD» {#the-tld-pricing-screen}

Откройте **Настройки → Цены на TLD**. Подзаголовок: «Настройка цен на доменные зоны и провайдеров».

**Столбцы:** TLD, Провайдер, Статус, Себестоимость (1 год), Продажа (1 год), Маржа, Категории, Последняя синхронизация.

Используйте поиск и фильтры, чтобы найти нужную зону.

Попытка найти настройку TLD, которой не существует, возвращает `TLD_CONFIG_NOT_FOUND`. Добавление уже существующего TLD возвращает `TLD_CONFIG_ALREADY_EXISTS`. Выбор провайдера-регистратора, которого система не знает, возвращает `TLD_REGISTRAR_MODULE_UNKNOWN`.

## Добавление TLD {#add-a-tld}

Нажмите **Добавить TLD** и заполните форму.

**Общие настройки:**
- **TLD** — зона без начальной точки (например, `com`, `net`, `am`).
- **Провайдер-регистратор** — какой регистратор обслуживает эту зону.
- **Валюта себестоимости** — валюта, в которой регистратор выставляет вам счёт.
- **Валюта продажи** — валюта, в которой вы выставляете счёт клиентам.
- **Включена** — отметьте, чтобы сделать этот TLD доступным для покупки.
- **Порядок сортировки** — позиция на витрине, от меньшего к большему.
- **Категории** — метки через запятую, которые используются как вкладки фильтра на витрине (например, `Popular,Business`).

**Таблицы цен** — заполните **Цены на регистрацию**, **Цены на перенос** и **Цены на продление**. В каждой таблице одна строка на каждый срок (от 1 до 10 лет):
- **Период** — число лет.
- **Себестоимость** — сколько берёт с вас регистратор.
- **Продажа** — сколько вы берёте с клиента.
- **Маржа** — рассчитывается автоматически.

Клиенты, которым счета выставляются не в валюте продажи, платят цену продажи, пересчитанную по сохранённым курсам обмена. Заказ, для которого нет подходящей строки цен, возвращает `ORDER_DOMAIN_PRICING_INVALID`.

Нажмите **Создать TLD**, чтобы сохранить.

## Импорт TLD у регистратора {#import-tlds-from-a-registrar}

Нажмите **Импорт** на экране «Цены на TLD» и выберите провайдера-регистратора. Пока список загружается у регистратора, на экране показано состояние импорта. По завершении появляется сообщение: «Импорт завершён: добавлено {imported}, обновлено {updated}.»

## Поддержание актуальности цен себестоимости {#keep-cost-prices-up-to-date}

Нажмите **Синхронизировать цены** на экране «Цены на TLD», чтобы получить актуальные цены себестоимости от всех провайдеров-регистраторов.

<Callout type="note">
«Синхронизировать цены» меняет только цены себестоимости. Цены продажи синхронизация никогда не меняет.
</Callout>

Ежедневное задание по умолчанию запускается в **04:00 UTC** и автоматически обновляет цены себестоимости и отметку **Последняя синхронизация** для всех TLD.

## Какой регистратор обслуживает домен {#which-registrar-handles-a-domain}

Когда заказывается новый домен, система подбирает настройку TLD с самым длинным совпадающим суффиксом. Например, если настроены и `am`, и `co.am`, домен `.co.am` использует настройку `co.am`. Если ни один суффикс не подходит, используется провайдер по умолчанию.

Существующий домен остаётся у того регистратора, у которого он был зарегистрирован, независимо от изменений настроек TLD.

## Категории на витрине {#categories-on-the-storefront}

Категории, перечисленные через запятую у каждого TLD, становятся вкладками фильтра **Просмотр по категориям** в процессе заказа в клиентском портале.
