# Транзакции, оплачиваемые позиции и коммерческие предложения <Label type="admin" /> {#transactions-billable-items-and-quotes}

## Транзакции {#transactions}

Откройте **Транзакции**, чтобы увидеть все финансовые события, записанные в системе.

**Фильтр «Показать»:** Вся активность, Полученные платежи, Отправленные платежи.

Вверху экрана показаны **итоговые суммы** за выбранный период: всего получено, всего отправлено и итог.

Значок **Вручную** отмечает транзакции, которые записал сотрудник, а не обработал шлюз.

### Добавление транзакции {#add-a-transaction}

Нажмите **Добавить транзакцию**, чтобы записать платёж или выплату, произошедшие вне процесса со счётом.

| Поле | Примечания |
|------|------------|
| Связанный клиент | Клиент, к которому относится транзакция |
| Поступление | Полученные деньги |
| Расход | Отправленные деньги |
| Комиссии | Комиссии шлюза или обработки |
| ID транзакции | Номер из вашего банка или шлюза |
| Способ оплаты | Как двигались деньги |
| ID счетов (через запятую) | Связывает транзакцию с одним или несколькими счетами |
| Добавить к кредитному балансу клиента | Отметьте, чтобы добавить чистую сумму как кредит |

У транзакции должна быть сумма поступления или сумма расхода (`TRANSACTION_AMOUNT_REQUIRED`).

Транзакция с отметкой **Добавить к кредитному балансу клиента** также является строкой истории кредита клиента (см. вкладку **Кредит** клиента). Её уже нельзя редактировать или удалять (`TRANSACTION_CREDIT_LOCKED`): исправляйте баланс корректировкой на вкладке «Кредит». Записи, сделанные до появления истории кредита, по-прежнему можно редактировать и удалять, а удаление такой записи отменяет её движение кредита. В этом списке показаны записи, по которым двигались деньги; кредит, применённый к счёту или скорректированный сотрудником, деньги не двигает и отображается только на вкладке «Кредит».

## Оплачиваемые позиции {#billable-items}

Откройте **Оплачиваемые позиции**, чтобы увидеть позиции, поставленные в очередь на выставление счёта.

**Статусы:**

| Статус | Значение |
|--------|----------|
| Не выставлено | Ждёт, пока ежедневное задание поместит её в счёт |
| Выставлено | Уже помещена в счёт |
| Повторяющаяся | Настроена на повторение; ещё не активна |
| Активные повторяющиеся | Сейчас формирует регулярные начисления |
| Завершённые повторяющиеся | Цикл повторения закончился |

### Добавление оплачиваемой позиции {#add-a-billable-item}

На странице клиента нажмите **Добавить оплачиваемую позицию**.

| Поле | Примечания |
|------|------------|
| Клиент | Клиент, которому выставляется начисление |
| Описание | Текст строки, который появится в счёте |
| Сумма | Сумма начисления |
| Валюта | Валюта счёта |
| Тип | Разовое или Повторяющееся |
| Дата выставления счёта | Дата, когда нужно выставить счёт по позиции |
| Период повторения | Еженедельно, Ежемесячно, Ежеквартально или Ежегодно (только для повторяющихся) |

Оплачиваемые позиции помещаются в счета ежедневным заданием обработки оплачиваемых позиций. Позицию, уже помещённую в счёт, изменить нельзя (`BILLABLE_ITEM_INVOICED`).

## Коммерческие предложения {#quotes}

Откройте **Предложения**, чтобы увидеть все коммерческие предложения. Предложения позволяют отправить клиенту расчёт стоимости и преобразовать его в счёт после принятия.

**Этапы:** Черновик, Доставлено, На паузе, Принято, Проиграно, Истекло, Неактуально.

### Создание предложения {#create-a-quote}

Нажмите **Создать предложение**.

<Steps>
<li>

Заполните **Тема**, **Этап**, **Клиент** и **Действительно до**.

</li>
<li>

Добавьте **Текст предложения** (его видит клиент), **Заметки для клиента** и **Заметки только для администраторов**.

</li>
<li>

Добавьте позиции: **Кол-во**, **Описание**, **Цена за единицу**, **Скидка %**, **С налогом**.

</li>
<li>

Нажмите **Сохранить**.

</li>
</Steps>

Предложение можно редактировать, только пока оно находится на этапе, который это допускает (`QUOTE_NOT_EDITABLE`). Принять можно только предложение на подходящем этапе (`QUOTE_NOT_ACCEPTABLE`).

### Дублирование и преобразование {#duplicate-and-convert}

- **Дублировать**: создаёт копию предложения на этапе «Черновик».
- **Преобразовать в счёт**: создаёт счёт из позиций предложения. Само предложение не меняется.

## Запросы на отмену {#cancellation-requests}

Откройте **Запросы на отмену**, чтобы увидеть запросы, отправленные клиентами.

Для каждого запроса показаны услуга, клиент и тип: **Немедленно** (отменить сейчас) или **В конце периода оплаты** (отменить в конце текущего срока).

Сотрудники действуют на самой записи услуги; этот экран только показывает и удаляет запросы.

## Выписка по клиенту {#client-statement}

Откройте **Отчёты → Баланс счёта клиента**, чтобы увидеть полную историю транзакций и текущий баланс клиента.
