# Транзакции, оплачиваемые позиции и коммерческие предложения <Label type="admin" /> {#transactions-billable-items-and-quotes}

## Транзакции {#transactions}

Откройте **Транзакции**, чтобы увидеть все финансовые события, записанные в системе.

Список разбивает на страницы сервер, поэтому любая запись доступна, сколько бы их ни было. Введите в строку поиска описание, ссылку, способ оплаты или номер записи, чтобы её найти; символы `%` и `_` в поиске обычные символы. Имена клиентов в поиске не ищутся, поэтому выберите клиента из списка. Кнопка **Фильтры** открывает эти поля, каждое после применения показано как чип, который можно убрать:

| Фильтр | Значение |
|--------|----------|
| Клиент | Только записи одного клиента, выбранного в списке клиентов |
| Показать | Вся активность, Полученные платежи (поступления) или Отправленные платежи (списания) |
| Способ оплаты | Только записи именно с этим способом оплаты |
| Диапазон дат | Первый и последний день; последний день включается до конца |
| Сумма | Только записи, у которых сумма поступления или сумма списания равна этой сумме |

Вверху экрана показаны **итоговые суммы** тех записей, которые оставили поиск и фильтры, а не всей книги: всего получено, всего отправлено, комиссии и итог в базовой валюте. Каждая валюта суммируется отдельно и только потом пересчитывается. Итоги и количество совпадают со строками, по которым вы листаете страницы.

Поиск, фильтры и страница сохраняются в адресе, поэтому перезагрузка или присланная ссылка показывает тот же список. Размер страницы больше 100, слишком длинный поиск, неизвестное направление, сумма не больше нуля или идентификатор клиента не больше нуля отклоняются, а не обрезаются. Вкладка **Транзакции** клиента имеет те же поиск и фильтры направления, способа оплаты, диапазона дат и суммы.

Значок **Вручную** отмечает транзакции, которые записал сотрудник, а не обработал шлюз.

### Добавление транзакции {#add-a-transaction}

Нажмите **Добавить транзакцию**, чтобы записать платёж или выплату, произошедшие вне процесса со счётом.

| Поле | Примечания |
|------|------------|
| Связанный клиент | Клиент, к которому относится транзакция |
| Поступление | Полученные деньги |
| Расход | Отправленные деньги |
| Комиссии | Комиссии шлюза или обработки |
| ID транзакции | Номер из вашего банка или шлюза |
| Способ оплаты | Как двигались деньги |
| ID счетов (через запятую) | Связывает транзакцию с одним или несколькими счетами |
| Добавить к кредитному балансу клиента | Отметьте, чтобы добавить чистую сумму как кредит |

У транзакции должна быть сумма поступления или сумма расхода (`TRANSACTION_AMOUNT_REQUIRED`).

Транзакция с отметкой **Добавить к кредитному балансу клиента** также является строкой истории кредита клиента (см. вкладку **Кредит** клиента). Её уже нельзя редактировать или удалять (`TRANSACTION_CREDIT_LOCKED`): исправляйте баланс корректировкой на вкладке «Кредит». Записи, сделанные до появления истории кредита, по-прежнему можно редактировать и удалять, а удаление такой записи отменяет её движение кредита. В этом списке показаны записи, по которым двигались деньги; кредит, применённый к счёту или скорректированный сотрудником, деньги не двигает и отображается только на вкладке «Кредит».

## Оплачиваемые позиции {#billable-items}

Откройте **Оплачиваемые позиции**, чтобы увидеть позиции, поставленные в очередь на выставление счёта. Список разбивается на страницы на сервере, поэтому любая позиция доступна, сколько бы их ни было.

Введите текст в строке поиска, чтобы найти позицию по описанию или номеру. Кнопка **Фильтры** открывает три поля; применённый фильтр показывается удаляемой меткой:

| Фильтр | Значение |
|--------|----------|
| Клиент | Только позиции одного клиента, выбранного в списке клиентов. Имя клиента в строку поиска вводить нельзя |
| Тип | Разовая или повторяющаяся |
| Выставлено | Да для позиций, уже помещённых в счёт, Нет для позиций, которые ждут ежедневного задания |

Тип и «Выставлено» работают вместе: повторяющиеся с «Выставлено: Нет» это активные повторяющиеся позиции, с «Выставлено: Да» те, чей цикл закончился.

На вкладке **Оплачиваемые позиции** клиента есть тот же поиск и фильтр по типу; они сужают и список невыставленных, и список выставленных позиций, а на страницы разбивается только список выставленных. Итог невыставленных считается по отфильтрованным позициям.

### Добавление оплачиваемой позиции {#add-a-billable-item}

На странице клиента нажмите **Добавить оплачиваемую позицию**.

| Поле | Примечания |
|------|------------|
| Клиент | Клиент, которому выставляется начисление |
| Описание | Текст строки, который появится в счёте |
| Сумма | Сумма начисления |
| Валюта | Валюта счёта |
| Тип | Разовое или Повторяющееся |
| Дата выставления счёта | Дата, когда нужно выставить счёт по позиции |
| Период повторения | Еженедельно, Ежемесячно, Ежеквартально или Ежегодно (только для повторяющихся) |

Оплачиваемые позиции помещаются в счета ежедневным заданием обработки оплачиваемых позиций. Позицию, уже помещённую в счёт, изменить нельзя (`BILLABLE_ITEM_INVOICED`).

## Коммерческие предложения {#quotes}

Откройте **Предложения**, чтобы увидеть все коммерческие предложения. Предложения позволяют отправить клиенту расчёт стоимости и преобразовать его в счёт после принятия.

**Этапы:** Черновик, Доставлено, На паузе, Принято, Проиграно, Истекло, Неактуально.

Список разбивает на страницы сервер. Введите в строку поиска тему или номер предложения, чтобы его найти; символы `%` и `_` в поиске обычные символы. Имена клиентов в поиске не ищутся, поэтому выберите клиента из списка. Кнопка **Фильтры** открывает эти поля, каждое после применения показано как чип, который можно убрать:

| Фильтр | Значение |
|--------|----------|
| Клиент | Только предложения одного клиента, выбранного в списке клиентов |
| Этап | Только предложения на этом этапе |
| Срок действия | «Действительно» для предложений, у которых дата «Действительно до» не прошла, «Истекло» для тех, у кого прошла. Смотрится только дата, поэтому предложение на этапе «Истекло» может иметь дату в будущем |

Поиск, фильтры и страница сохраняются в адресе, а сервер применяет их до разбиения на страницы. Вкладка **Предложения** клиента имеет те же поиск и фильтры этапа и срока действия.

### Создание предложения {#create-a-quote}

Нажмите **Создать предложение**.

<Steps>
<li>

Заполните **Тема**, **Этап**, **Клиент** и **Действительно до**.

</li>
<li>

Добавьте **Текст предложения** (его видит клиент), **Заметки для клиента** и **Заметки только для администраторов**.

</li>
<li>

Добавьте позиции: **Кол-во**, **Описание**, **Цена за единицу**, **Скидка %**, **С налогом**.

</li>
<li>

Нажмите **Сохранить**.

</li>
</Steps>

Предложение можно редактировать, только пока оно находится на этапе, который это допускает (`QUOTE_NOT_EDITABLE`). Принять можно только предложение на подходящем этапе (`QUOTE_NOT_ACCEPTABLE`).

### Дублирование и преобразование {#duplicate-and-convert}

- **Дублировать**: создаёт копию предложения на этапе «Черновик».
- **Преобразовать в счёт**: создаёт счёт из позиций предложения. Само предложение не меняется.

## Запросы на отмену {#cancellation-requests}

Откройте **Запросы на отмену**, чтобы увидеть запросы, отправленные клиентами.

Для каждого запроса показаны услуга, клиент и тип: **Немедленно** (отменить сейчас) или **В конце периода оплаты** (отменить в конце текущего срока).

Введите текст в строке поиска, чтобы найти запрос по причине или номеру. Кнопка **Фильтры** открывает поля «Тип» и «Статус» (открыт или закрыт); применённый фильтр показывается удаляемой меткой. Искать по названию услуги или имени клиента нельзя.

Сотрудники действуют на самой записи услуги; этот экран только показывает и удаляет запросы.

## Выписка по клиенту {#client-statement}

Откройте **Отчёты → Баланс счёта клиента**, чтобы увидеть полную историю транзакций и текущий баланс клиента.
